# my-3d-setup

Личный репозиторий настройки и эксплуатации 3D-принтера **Flashforge Adventurer 5M Pro**.

Здесь живёт всё, что относится к принтеру: спеки и сетевые координаты, прошивки и их бэкапы, конфиги Klipper, профили слайсера, результаты калибровочных тестов, аппаратные моды, инвентарь инструментов и филаментов, ссылки на модели и журнал работ.

## Текущий статус

- Принтер только распакован, подключён к Wi-Fi.
- Прошивка: **stock**, заводская.
- Камера и веб-интерфейс доступны в локальной сети.
- Сетевые координаты — в [printer/network.md](printer/network.md).

## План развития

1. Добить заводские демо-печати, обкатка.
2. Систематические калибровочные тесты на стоковой прошивке.
3. Переход на **Forge-X mod** → дальше **Klipper**.
4. Аппаратные моды по мере необходимости.

Подробнее по этапам — в [firmware/README.md](firmware/README.md) и [calibration/README.md](calibration/README.md).

## С чего начать

- Новой сессии Claude — открыть [CLAUDE.md](CLAUDE.md).
- Человеку — открыть [printer/README.md](printer/README.md).
- По любому разделу — внутри лежит свой `README.md` с описанием папки.

## Принципы

- В каждой папке есть свой `README.md`, объясняющий назначение и содержимое.
- Тяжёлые артефакты (`*.gcode`, большие `*.stl`, видео с камеры) в репу не коммитятся — см. [.gitignore](.gitignore).
- Записи в журнале — по дате, формат `journal/YYYY-MM-DD-краткая-тема.md`.
