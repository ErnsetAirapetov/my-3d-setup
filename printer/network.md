# Сетевые координаты принтера

Зафиксированные адреса для доступа к принтеру в локальной сети.

## Базовые

| Параметр | Значение |
| --- | --- |
| Локальный IP | `192.168.1.134` |
| MAC-адрес | _TBD_ |
| Hostname | _TBD_ |
| Сеть | домашний Wi-Fi |

> Желательно выдать на роутере **DHCP-резервацию** для MAC принтера, чтобы IP не менялся. Когда настроишь — впиши MAC сюда.

## Камера

- Поток (MJPEG): `http://192.168.1.134:8080/?action=stream`.
- Снимок (если поддерживается): `http://192.168.1.134:8080/?action=snapshot`.
