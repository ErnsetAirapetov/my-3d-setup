# Сетевые координаты принтера

Зафиксированные адреса для доступа к принтеру в локальной сети.

## Базовые

| Параметр | Значение |
| --- | --- |
| Локальный IP | `192.168.1.134` |
| MAC-адрес | `24:A1:0D:B2:AA:8E` |
| Hostname | _TBD_ |
| Сеть | домашний Wi-Fi |

> Желательно выдать на роутере **DHCP-резервацию** для MAC `24:A1:0D:B2:AA:8E`, чтобы IP не менялся.

## Идентификация принтера для API

| Параметр | Значение | Где найти |
| --- | --- | --- |
| Serial Number | `SNMOME9C00678` | TCP API `~M115`; на наклейке принтера |
| Check Code | `a3356b04` | экран принтера (Network info) |

## Камера

- Поток (MJPEG): `http://192.168.1.134:8080/?action=stream`.
- Снимок: эндпоинт `?action=snapshot` принтером **не отдан** (в стоке поток без отдельного снимка).

## Открытые порты

Сканирование от 2026-04-26:

| Порт | Протокол | Что отдаёт |
| --- | --- | --- |
| 8080 | HTTP (mjpg-streamer) | поток с камеры |
| 8898 | HTTP REST | Flashforge HTTP API (требует LAN-mode + SN/checkCode) |
| 8899 | TCP plain text | M-code API, отвечает без авторизации |

Порты 80, 443, 7125 (Moonraker), 5000/5001 — закрыты на стоке.

## TCP API (порт 8899)

Простой текстовый протокол: M-команды с префиксом `~`, разделитель `\r\n`, ответ заканчивается строкой `ok`.

Полезные команды (проверено):

| Команда | Что возвращает |
| --- | --- |
| `~M115` | модель, прошивка, SN, рабочее поле X/Y/Z, MAC, Tool count |
| `~M105` | температуры: T0/T1 (нозлы), B (стол), формат `current/target` |
| `~M27` | прогресс печати, текущий слой |
| `~M114` | текущая позиция X/Y/Z |
| `~M119` | состояние эндстопов и MachineStatus (READY/PRINTING/...) |
| `~M650` | возвращает `X: 1.0 Y: 0.5` (назначение TBD) |
| `~M661` | список файлов в `/data/` |

Пример из bash:

```bash
exec 3<>/dev/tcp/192.168.1.134/8899
printf '~M115\r\n' >&3
timeout 1 cat <&3
exec 3<&-; exec 3>&-
```

## HTTP API (порт 8898)

REST API. Все эндпоинты — POST с JSON-телом, в теле обязательны `serialNumber` и `checkCode`. На стоке принтера **требует включённого LAN-режима** в настройках, иначе любой запрос возвращает `{"code":-2,"message":"Lan mode error"}`.

Эндпоинты, на которые принтер реагирует (отвечают 200 OK после включения LAN-mode):

| Путь | Назначение |
| --- | --- |
| `POST /detail` | детальный статус (печать, температуры, прогресс) |
| `POST /product` | информация о принтере |
| `POST /control` | команды управления |

Чтобы включить — на экране принтера: **Settings → Network → LAN Mode** (точное название уточнить).

## Точка доступа принтера (Wi-Fi hotspot)

Если поднять режим AP на принтере:

| Параметр | Значение |
| --- | --- |
| SSID | `Adventurer5M Pro` |
| Пароль | `12345678` |
| IP принтера в режиме AP | `192.168.0.240` |

## После Klipper

Когда поставим Klipper, тут добавятся:

- Mainsail / Fluidd UI: `http://192.168.1.134/`.
- Moonraker API: `http://192.168.1.134:7125/`.

## История изменений

- **2026-04-26** — принтер первый раз подключён к Wi-Fi, IP `192.168.1.134`. Через TCP `~M115` подтверждены SN/MAC/прошивка/рабочее поле.
