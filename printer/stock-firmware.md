# Стоковая прошивка

Заметки по заводской прошивке Flashforge Adventurer 5M Pro: версия, что умеет, ограничения, известные баги.

## Версия

- **Версия прошивки:** `v3.2.7` (получено через `~M115` на TCP-порту 8899, 2026-04-26).
- **Версия Flashforge-приложения:** _TBD_.
- **SN принтера:** `SNMOME9C00678`.

## Что умеет (по факту наблюдений)

- Печать с внутренней памяти (`/data/`) — на старте было **8 демо-моделей**: Boat, Concave Dodecahedron, Cube-PLA-Test, Keychain, Desk Organizer, Touch Pen, Mobile phone holder, Icecream.
- Wi-Fi подключение к домашней сети + AP-режим (Wi-Fi hotspot, см. [network.md](network.md)).
- Камера — поток MJPEG на порту 8080.
- TCP M-code API на 8899 — отвечает без авторизации.
- HTTP REST API на 8898 — есть, но требует включённого LAN-режима в настройках.
- Auto bed leveling (one-tap) — есть по datasheet, проверим в первой калибровке.
- Через приложение Flashforge: загрузка моделей, мониторинг, удалённое управление через облако.

## Ограничения / зачем нужны Forge-X / Klipper

- Нет тонкой настройки в духе Klipper: pressure advance, input shaper, кастомные макросы, bed mesh с перекалибровкой по нужным точкам.
- Закрытая экосистема, рут-доступ к ОС из коробки отсутствует — для аппаратных модов и полного контроля нужен Forge-X mod (даёт root) и далее Klipper.
- Профили филаментов и slicer в облаке/приложении менее гибкие, чем в OrcaSlicer + Klipper.

## Команды TCP API (порт 8899, шпаргалка)

См. [network.md](network.md) → раздел «TCP API». Минимально полезные:

- `~M115` — модель / прошивка / SN / рабочее поле / MAC.
- `~M105` — температуры hotend и стола.
- `~M27` — прогресс текущей печати.
- `~M119` — состояние эндстопов и MachineStatus.
- `~M661` — список файлов в `/data/`.

## Бэкапы

Файлы и снимки настроек со стока лежат в [../firmware/stock/](../firmware/stock/).

Перед любой прошивкой (Forge-X / Klipper) — обязательно:
1. Сохранить версию `v3.2.7` (зафиксировано здесь).
2. Снять скриншоты экрана с настройками сети, печати, термистора, скоростей.
3. Сохранить SN, CheckCode, MAC ([network.md](network.md)) в актуальном виде.
