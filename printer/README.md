## Сеть и API

Полные координаты — в [network.md](network.md). Кратко:

- IP в LAN: `192.168.1.134`.
- Камера (MJPEG): `http://192.168.1.134:8080/?action=stream`.
- TCP API (M-коды): порт **8899** — работает без авторизации, отвечает в LAN-mode и без него.
- HTTP API (REST): порт **8898** — требует включённого **LAN-режима** в настройках принтера + `serialNumber` и `checkCode` в теле POST.

Точка доступа принтера (если поднять режим Wi-Fi-хотспота):

- SSID: `Adventurer5M Pro`
- Пароль: `12345678`
- IP принтера в режиме AP: `192.168.0.240`
