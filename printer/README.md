# printer/ — источник правды по железу

Здесь живёт всё, что описывает **физический принтер**: модель, спеки, серийники, сетевые координаты, состояние стоковой прошивки. Это первая папка, в которую открывается репа: любая работа по конфигам, прошивкам или калибровке начинается с актуальных данных отсюда.

## Что внутри

- [README.md](README.md) — этот файл. Спеки и текущее состояние.
- [network.md](network.md) — сетевые координаты: IP, камера, веб-интерфейсы, порты.
- [stock-firmware.md](stock-firmware.md) — заметки по заводской прошивке: что умеет, ограничения.

## Принтер

- **Модель:** Flashforge Adventurer 5M Pro.
- **Дата старта эксплуатации:** 2026-04-26.
- **Текущая прошивка:** заводская (stock).
- **Состояние:** распакован, подключён к Wi-Fi, обкатывается на демо-печатях из внутренней памяти.
