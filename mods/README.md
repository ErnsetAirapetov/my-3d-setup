# mods/ — аппаратные модификации

Любые **аппаратные** изменения принтера: замена деталей, добавление сенсоров, новые сопла, направляющие, обвес. Софт-модификации (прошивки, конфиги) живут в [../firmware/](../firmware/).

## Принципы

- **Сначала калибровка, потом моды.** Без бейзлайна с заводскими параметрами невозможно понять, что мод реально дал.
- **Один мод за раз.** После каждого мода — повторный прогон ключевых тестов. Иначе невозможно отделить эффекты разных модов.
- **Обратимость.** По возможности храним заводскую деталь, чтобы можно было откатиться.
- **Документировать всё.** Дата, причина, источник детали, фото до/после, изменения в конфиге.

## Структура

- [planned.md](planned.md) — список потенциальных модов с обоснованием.
- [installed/](installed/) — папка на каждый установленный мод.

## Шаблон папки установленного мода

```
installed/<YYYY-MM-DD-mod-name>/
├── README.md       # Что, зачем, источник, фото, ссылки на изменения в конфигах
└── photos/         # До/после, процесс установки
```
