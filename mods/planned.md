## Внешний Klipper-хост — BIGTREETECH CB1 + PI4B Adapter

- **Приоритет:** высокий
- **Статус:** железо куплено и собрано (CB1 насажен на PI4B Adapter, радиатор установлен). К принтеру **не подключён**, Klipper-миграция впереди.
- **Зачем:** AD5M Pro **сам** запускает полный Klipper-стек на своём бортовом хосте (Allwinner T113-S3, **всего 128 МБ RAM**) через мод Forge-X — отдельная плата для базового Klipper **не нужна**. CB1 берёт роль **всегда включённого домашнего сервера-разгрузчика**: на 128 МБ душатся тяжёлые сервисы, и мы выносим их на CB1 — **Telegram-бот** (`moonraker-telegram-bot`), **Spoolman** (учёт филамента), **Tailscale** (удалёнка), **mobileraker-companion** (push), рендер таймлапсов, git-бэкапы. CB1 общается с принтером **по сети** через Moonraker API — **не** проводом к MCU, свой хост у принтера сохраняется. Камера пока остаётся встроенной в принтер. Полная карта — [ARCHITECTURE.md](../ARCHITECTURE.md).
- **Источник детали:** AliExpress, артикул `1005009188929908`, комплект «CB1 + PI4B + Heatsink», ~2 909 ₽.
- **Зависимости:** Klipper на принтере (см. [firmware roadmap](../firmware/README.md): stock → Forge-X → Klipper) и общая LAN. Для самого CB1: microSD-карта (с неё грузится, своей eMMC у V2.2 нет), питание 5V/2A (Type-C на адаптере), ОС (готовый BTT CB1-образ или Armbian/Debian). Проводной линк к плате принтера **не требуется**.
- **Риски:** дополнительная точка отказа и обслуживания (ещё одна ОС, обновления, бэкапы); 100 Мбит сеть и 2.4 ГГц Wi-Fi (для роли сервера достаточно, но не гигабит, как можно подумать по подписи порта на адаптере); соблазн переусложнить — начинать стоит с принтера, CB1 подключать вторым этапом.

> ⚠️ Это **не «мини-ПК»** в смысле x86-коробки (N100 и т.п.), а **одноплатный компьютер (SBC)**: вычислительный модуль BIGTREETECH **CB1** (формат, совместимый с Raspberry Pi CM4) на плате-носителе **PI4B Adapter**, которая придаёт ему форм-фактор и порты Raspberry Pi 4B. Связка делается специально под Klipper как замена «малинки».

### Спеки — BIGTREETECH CB1 (V2.2, вычислительный модуль)

| Параметр | Значение |
| --- | --- |
| SoC | Allwinner **H616**, 4× Cortex-A53 @ 1.5 ГГц (64-bit ARM) |
| GPU | Mali G31 MP2 (OpenGL ES 3.2) |
| RAM | **1 ГБ** DDR3L |
| Хранилище | загрузка с **microSD** (своей eMMC у V2.2 нет; есть отдельная версия «CB1 eMMC») |
| Сеть | **100 Мбит** Ethernet + Wi-Fi **2.4 ГГц** 802.11 b/g/n |
| Видеовыход | HDMI 2.0a, до 4K |
| Питание | 5V ±5% / 2A |
| Размер модуля | 40 × 55 мм; крепёж 33 × 48 мм |
| BTB-разъём | как у Raspberry Pi CM4 |

### Спеки — BIGTREETECH PI4B Adapter (плата-носитель)

| Параметр | Значение |
| --- | --- |
| Назначение | носитель для CB1 / Raspberry Pi CM4, придаёт форм-фактор Raspberry Pi 4B |
| Ethernet | гигабитный порт физически, но с CB1 работает на **100 Мбит** (ограничение модуля) |
| USB | 4× USB 2.0 |
| Видео | 2× micro-HDMI |
| Камера/дисплей | разъёмы CSI (камера) + DSI (дисплей) |
| Накопитель | слот microSD |
| Питание | Type-C (питает всю систему; также прошивка eMMC для CM4) |
| GPIO | 40-pin, распиновка как у Raspberry Pi |
| Прочее | 5V-разъём вентилятора, ESD-защита USB и сети |
