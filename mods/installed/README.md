# mods/installed/

Установленные аппаратные моды. Каждый мод — отдельная папка с датой в имени: `YYYY-MM-DD-mod-name/`.

Внутри папки мода — `README.md` с описанием (что, зачем, откуда деталь, что изменилось в конфиге, фото) и при необходимости подпапка `photos/`.

Шаблон оформления — см. [../README.md](../README.md).
