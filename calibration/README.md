# calibration/ — тесты и калибровка

Систематическая калибровка принтера. План тестов идёт в порядке: сначала **механика**, потом **термика**, потом **тонкая настройка** (требует Klipper).

Каждый выполненный тест получает свою папку в [tests/](tests/) с STL/3MF, фотками и markdown-замерами. Подпапки **создаются по факту**, не наперёд — пустые папки только мешают навигации.

## План тестов

### Этап 1. Механика (на стоке, после обкатки)

| Тест | Цель | Нужно из инструмента |
| --- | --- | --- |
| `first-layer` | Подобрать squish первого слоя, выровнять стол | Линейка / визуальный осмотр |
| `orthogonality` | Проверить, что оси X/Y/Z взаимно перпендикулярны | Угольник, штангенциркуль |
| `sorkin-xyz` | Калибровочный кубик: размеры, скос, дефекты | **Штангенциркуль 0.01 мм** |
| `bed-mesh` (см. [bed-mesh/](bed-mesh/)) | Снять карту высот стола, понять рельеф | — |

### Этап 2. Термика (на филамент)

| Тест | Цель |
| --- | --- |
| `temperature-tower` | Найти оптимальную температуру для конкретного филамента |
| `retraction` | Подобрать длину/скорость ретракта (минимизировать стринги) |
| `flow-rate` | Калибровка потока (Extrusion Multiplier) |

### Этап 3. Тонкая настройка (после Klipper)

| Тест | Цель |
| --- | --- |
| `pressure-advance` | PA для устранения «слизней» на углах |
| `input-shaper` | IS для подавления резонансов, повышения скорости |

## Как делать тест

1. Создать папку `tests/<test-name>/` (если ещё нет).
2. Положить туда STL/3MF и `README.md` с условиями: дата, прошивка, филамент, температура, скорость.
3. Распечатать.
4. Замерить, сфоткать, записать результаты в `README.md` теста.
5. Если тест проходился повторно (после мода, апгрейда) — добавить новую запись с датой, **не затирая старую**. Это даёт историю «до и после».
