# calibration/ — тесты и калибровка

Систематическая калибровка принтера. План тестов идёт в порядке: сначала **механика** (без расходников и с минимумом инструментов), потом **размерная точность** (со штангенциркулем), потом **под филамент** (термика и поток), потом **regression** (всё вместе), потом **тонкая настройка** (требует Klipper).

Каждый выполненный тест получает свою папку в [tests/](tests/) с STL/3MF, фотками и markdown-замерами. У каждой папки уже есть `README.md` с методикой; подпапки прогонов / фотки складываются по факту прогона.

## План тестов по этапам

### Этап 1. Pre-flight + первый слой (можно прямо сейчас)

Без штангенциркуля. Что делается до того, как мы вообще можем кому-то верить.

| Тест | Цель | Нужно | Документ |
| --- | --- | --- | --- |
| Pre-flight | Натяжение ремней, чистота сопла и стола, auto-bed-leveling | глаза, IPA | (журнальная запись) |
| `first-layer` | Подобрать squish первого слоя через Z-offset | глаза | [tests/first-layer/](tests/first-layer/) |
| `bed-mesh` | Снять и сохранить карту высот стола | данные с принтера | [bed-mesh/](bed-mesh/) |

**Без рабочего первого слоя дальше идти бессмысленно** — все измерения будут врать.

### Этап 2. Размерная точность и геометрия (нужен штангенциркуль)

Проверяем механику принтера независимо от филамента.

| Тест | Цель | Документ |
| --- | --- | --- |
| `xyz-cube` | Размеры по X / Y / Z, общее качество, диагонали | [tests/xyz-cube/](tests/xyz-cube/) |
| `orthogonality` | Перпендикулярность осей X ↔ Y | [tests/orthogonality/](tests/orthogonality/) |
| `sorkin` | Диагностический плат: линии, отверстия, штифты, тонкие фичи | [tests/sorkin/](tests/sorkin/) |
| `threaded-fit` | Functional fit: винт реально вкручивается, отверстия правильного диаметра | [tests/threaded-fit/](tests/threaded-fit/) |

Эти тесты **не зависят от конкретного филамента** (на одном PLA достаточно). Если кубик неточный — проблема в механике, идти в термику не надо.

### Этап 3. Под филамент (термика + поток)

На каждый филамент. Записываем результаты в файлы по катушке внутри папки теста.

| Тест | Цель | Документ |
| --- | --- | --- |
| `temperature-tower` | Оптимальная температура сопла | [tests/temperature-tower/](tests/temperature-tower/) |
| `retraction` | Минимальный ретракт без stringing-а | [tests/retraction/](tests/retraction/) |
| `flow-rate` | Extrusion Multiplier (поток) | [tests/flow-rate/](tests/flow-rate/) |

Порядок внутри этапа важен: **сначала температура, потом ретракт, потом flow** — каждый следующий зависит от стабильности предыдущего.

### Этап 4. Regression (всё вместе)

| Тест | Цель | Документ |
| --- | --- | --- |
| `all-in-one` | Stress-тест: ретракция, мост, нависы, отверстия, надписи в одной модели | [tests/all-in-one/](tests/all-in-one/) |

Делается **после** этапов 1–3. Цель — увидеть, как настройки работают в комплексе. Также прогоняется **после любого мода или смены прошивки** (Forge-X, Klipper) для отлова регрессий.

### Этап 5. Тонкая настройка (после Klipper)

Не на стоке. Эти параметры либо неконфигурируемы из заводской прошивки, либо настраиваются неудобно.

| Тест | Цель |
| --- | --- |
| `pressure-advance` | PA для устранения «слизней» на углах и точных отверстий |
| `input-shaper` | IS для подавления резонансов, повышения скорости |
| `vfa` (K3D VFA Test) | Поиск скоростей, на которых появляется рябь. На стоке смысла мало, на Klipper — связка с input-shaper. Модель: https://k3d.tech/calibrations/vfa/ |

## Как делать тест

1. Открыть `tests/<test-name>/README.md` — там методика и шаблон записи.
2. Скачать модель по ссылке (или сгенерировать в Orca-Flashforge встроенно), положить в эту же папку.
3. Распечатать с **текущим стандартным** профилем (если в методике не сказано иначе).
4. Замерить, сфоткать, записать прогон в файл `<YYYY-MM-DD>-prog<N>.md` или `<filament-name>.md` — формат указан в README теста.
5. Если тест проходился повторно (после мода / правки) — добавлять новую запись с датой, **не затирая старую**. Это даёт историю «до и после».
