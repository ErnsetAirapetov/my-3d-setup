# threaded-fit — тест посадки винта в отверстие (functional fit)

## Зачем

Это **функциональный тест на «реальной задаче»**. Вместо абстрактных миллиметров мы проверяем то, ради чего обычно и печатают: **деталь, в которую вкручивается винт**, не должна ломаться, лопаться или болтаться. Размеры могут быть «в норме» по штангенциркулю, а реальный винт всё равно не лезет — потому что виноват слайсер (XY hole compensation), pressure advance, или специфика отверстий, которые принтер всегда печатает чуть меньше номинала.

## Что проверяет

- Точность отверстий заданного диаметра (М3, М4, М5).
- Качество резьбовых отверстий, если на модели есть напечатанная резьба.
- «Tolerance fit»: насколько разница между двумя деталями (хвостовик и втулка) воспроизводится принтером.
- Косвенно — pressure advance и поведение принтера на коротких/мелких контурах.

## Что нужно

- **Инструменты:** реальные металлические винты — М3, М4, М5 разной длины (10–20 мм). Штангенциркуль для контрольного замера.
- **Филамент:** PLA.
- **Слайсер:** Orca-Flashforge, стандартный профиль.

## Варианты модели

Тест существует в нескольких видах — выбирай по задаче:

| Тип | Описание | Когда брать |
| --- | --- | --- |
| **Простое отверстие под винт** | плоский квадрат с дыркой Ø3 / 4 / 5 — без резьбы, винт проходит насквозь | первая проверка размеров отверстий; быстро |
| **Резьбовое отверстие (printed thread)** | напечатанная резьба М3/М4/М5 в отверстии; винт **вкручивается** | проверка тонкого рельефа; сильнее зависит от слайсера и качества стенок |
| **Tolerance test** | хвостовик заданного диаметра, который должен войти во втулку с зазорами 0.1 / 0.2 / 0.3 мм | для функциональных деталей где важен точный fit |

## Откуда взять модель

- **Printables / Thingiverse** — поиск:
  - `«screw test»`, `«screw thread test»`, `«threaded hole test»`.
  - `«tolerance test»` (Maker's Muse - известный автор), `«clearance test»`.
- В Orca-Flashforge **встроенной** генерации этого теста **нет** — нужно скачивать модель.

## Как делать (методика)

1. **Сначала откалибровать flow rate и temperature.** Если экструзия неровная, отверстия будут гулять — тест не покажет посадку, покажет проблемы экструдера.
2. Загрузить модель, нарезать **стандартным** профилем (тот, которым обычно печатаешь функциональные детали).
3. Не уменьшай скорость на тонких контурах вручную — мы тестируем **реальный** профиль.
4. Печатать. Дать остыть.
5. **Не сверлить** отверстия для проверки — это маскирует проблему. Только winвинты.
6. Попытаться:
   - Просунуть винт в отверстие без резьбы — должен пройти **с лёгким зазором**, не клиниться, не болтаться.
   - Вкрутить винт в резьбовое отверстие — должен идти **рукой, без отвёртки или с минимальным усилием**, не срывая виток. Пройти полностью на длину 5–10 мм.
   - Соединить tolerance-пары — отметить, какой зазор «работает» (входит свободно, без люфта).

## Как читать результаты

| Симптом | Возможная причина | Действие |
| --- | --- | --- |
| Винт **не лезет** в отверстие без резьбы | отверстия меньше номинала | Включить **«XY hole compensation»** в Orca (положительное значение `+0.05…+0.15 мм`); или прогнать [flow-rate](../flow-rate/) |
| Винт **болтается**, отверстие большое | over-extrusion / hole compensation в минус | Уменьшить hole compensation до `0`; прогнать [flow-rate](../flow-rate/) |
| В резьбовое отверстие винт **проходит первые 1–2 витка**, дальше клинит | резьба недопечатана: пластик в желобах | Снизить температуру на 5°C / снизить скорость / включить ironing на верхней грани; pressure advance даст лучший эффект — после Klipper |
| Резьба **срывается** при вкручивании | стенки слабые: либо мало стенок, либо плохая адгезия слоёв | Увеличить количество перимétров (walls) до 3–4; повысить температуру для лучшей адгезии слоёв |
| Tolerance: только зазоры ≥ 0.3 мм работают | принтер «толстит» при печати | Прогнать [flow-rate](../flow-rate/) и [temperature-tower](../temperature-tower/) |
| Tolerance: даже 0.1 мм входит свободно | принтер «худеет», возможно under-extrusion | Увеличить flow на 1–2% |
