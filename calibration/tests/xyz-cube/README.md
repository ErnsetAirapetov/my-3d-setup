# xyz-cube — калибровочный кубик 20 мм

## Зачем

Это **базовый тест размерной точности** принтера и одновременно общий чекап качества: углы, грани, верхняя крышка, мелкий рельеф (буквы X/Y/Z на гранях). Если кубик печатается «коряво», нет смысла идти дальше — все остальные тесты будут работать с искажёнными цифрами.

## Что проверяет

- Размерную точность по осям X, Y, Z (должны быть `20.00 мм` ± допуск).
- Перпендикулярность граней (визуально + диагонали).
- Качество поверхностей: верх (top layers), стенки (walls), нижняя плоскость (first layer).
- Качество мелкого рельефа: буквы X / Y / Z должны быть читаемыми и одинаково чёткими на трёх гранях.
- Углы: ringing/ghosting, скос, бочкообразность.

## Что нужно

- **Инструменты:** **цифровой штангенциркуль (0.01 мм) — обязательно.**
- **Филамент:** PLA, желательно одного цвета без светоотражающих/глиттер-добавок (мешают разглядеть дефекты).
- **Слайсер:** Orca-Flashforge, текущий профиль PLA + machine 5M Pro.
- **Время:** ~30–40 минут печати + 10 минут замеров.

## Как делать (методика)

1. **Не запускать раньше first-layer теста.** Сначала калибруется первый слой; иначе кубик будет «лежать криво» с самого основания.
2. Загрузить STL в Orca-Flashforge, нарезать с **текущим стандартным профилем** PLA. Никаких особых настроек — мы тестируем «как будем печатать обычно».
3. Поставить модель **в центр стола** (если будут разовые выезды стола, центр самый предсказуемый).
4. Печатать.
5. Дать **полностью остыть** (пластик ужимается при остывании; горячий замер врёт).
6. Аккуратно снять, очистить нижнюю плоскость от brim-а / artifact-ов.

## Как замерять

**По каждой оси — три точки.** Это критично: одна точка ничего не говорит.

| Ось | Точки замера |
| --- | --- |
| **X** | низ передней грани, середина передней грани, верх передней грани |
| **Y** | низ боковой грани, середина боковой грани, верх боковой грани |
| **Z** | передний край верхней грани, центр, задний край верхней грани |

Дополнительно:

- **Диагонали верхней грани** (D1 и D2) — проверка ортогональности X↔Y.
- **Скос** (если визуально видно): измерить разницу размеров на низу и верху по той же оси.

Записывать в таблицу.

## Как читать результаты

| Что видно | Возможная причина | Что делать |
| --- | --- | --- |
| X = Y, оба = 20.10 мм или больше; Z в норме | over-extrusion, слишком много пластика | Уменьшить **Flow** (Extrusion Multiplier) на 1–2 % и/или прогнать [flow-rate](../flow-rate/) |
| X = Y, оба = 19.90 мм или меньше | under-extrusion | Увеличить Flow и/или посмотреть профиль филамента (диаметр?) |
| X != Y (один 20.00, другой 20.15) | разная плотность шагов осей или один ремень слабо натянут | Прогнать [orthogonality](../orthogonality/), проверить ремни |
| Z отклоняется, но шагом, кратным `0.2 мм` (высота слоя) | проблема не в шагах Z, а в первом слое (Z-offset зашёл в основание) | Перепечатать первый слой, повторить кубик |
| Z больше ожидаемого на ~0.05–0.15 мм | first-layer пере-squished или верх «вспучен» (pillowing) | Поднять Z-offset на +0.05; проверить охлаждение верха |
| Бочкообразность (середина больше, чем края) | разогрев камеры тянет деталь / belt slack под нагрузкой | Проверить ремни, попробовать ниже температуру |
| Скос (низ больше, верх меньше) | Z-стол не параллелен XY / каретка имеет наклон | Re-level, посмотреть [bed-mesh](../../bed-mesh/) |
| Ringing на гранях (волны после углов) | вибрации, скорость/ускорения слишком высоки | Снизить acceleration; полноценно решается через input-shaper после Klipper |
| Углы скруглённые (corners rounded), хотя должны быть чёткими | под-extrusion на углах + замедлении | На стоке — мало что сделаешь; нормально решается через pressure-advance после Klipper |
| Буквы X/Y/Z размытые, особенно одна из трёх | под-extrusion / температура / охлаждение | Прогнать [temperature-tower](../temperature-tower/) |
| D1 != D2 (диагонали верхней грани) | оси X и Y не перпендикулярны | См. [orthogonality](../orthogonality/) |
