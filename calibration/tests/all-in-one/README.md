# all-in-one — комбинированный stress-тест печати

## Зачем

Это **regression-тест**. Не для калибровки одной конкретной фичи — для проверки, что **«всё печатается одновременно»**: ретракция между башнями, мост, нависы, отверстия, мелкий текст, разные диаметры. То самое «несколько башен + наклонный мостик + странные отверстия», которое часто видишь на фото красивых printer-сетапов.

**Когда печатать:**
- После того как уже откалибровали flow / temperature / retraction по отдельности — проверить, что они вместе работают.
- После любого мода или смены прошивки (Forge-X, Klipper) — увидеть, не сломалось ли что-то комплексно.
- После смены филамента или сопла.

Не используется для **первичной** настройки — на нём слишком много фич сразу, неясно, кто из них «виноват» если что-то плохо. Сначала настраиваем по отдельным тестам, потом проверяем всё вместе **здесь**.

## Что проверяет одновременно

- **Retraction между башнями** — должно быть чисто, без соплей и нитей.
- **Bridging** (мост) — насколько провисает, есть ли спагетти.
- **Overhangs** разных углов (обычно 30 / 45 / 60°) — droop, спагетти, вкривь.
- **Holes** — круглость, размер.
- **Маленькие пины и башни** — стабильность, ringing.
- **Текст / надписи** — мелкий рельеф.
- **Surface finish** — однородность, видимые слои, артефакты.

## Что нужно

- **Инструменты:** глаза (фотографируй) + штангенциркуль.
- **Филамент:** PLA с уже подобранными температурой и потоком.
- **Слайсер:** Orca-Flashforge, **стандартный** профиль PLA. Если меняешь параметры на этом тесте — теряется смысл «regression».

## Откуда взять модель

| Источник | Заметка |
| --- | --- |
| **Printables**, поиск **«all in one 3d printer test»** | самый популярный (тысячи лайков) — обычно одна модель: 3 ретракционные башни + наклонный мост + пины + дыры + надпись. Брать по числу лайков и комментариев. |
| **Thingiverse**, поиск **«torture test»** или **«print quality test»** | классические варианты, более старые |
| **Voron Cube** / **Voron benchy** | альтернативный benchmark, более «спокойный» |
| **3DBenchy** | упрощённый, без ретракции — годится только как «глянь, всё ли в порядке» |

> Скачанную модель кинуть в эту папку. Авторство и лицензию записать в файл прогона.

## Как делать (методика)

1. Все базовые тесты пройдены: [first-layer](../first-layer/), [xyz-cube](../xyz-cube/), [temperature-tower](../temperature-tower/), [retraction](../retraction/), [flow-rate](../flow-rate/).
2. Положить модель в Orca, нарезать **стандартным** профилем (без замедлений, без особых режимов).
3. Печатать в центре стола.
4. Дать остыть.
5. Сделать **много фото**: фронт, бэк, верх, нависы крупно, мост крупно, башни ретракции крупно.
6. По каждой фиче — оценка по шкале «✅ ок / ⚠️ есть замечания / ❌ провал» с комментарием.

## Как читать результаты (по фичам)

### Башни ретракции (между ними соединительные перемычки или нити)

| Что видно | Причина | Действие |
| --- | --- | --- |
| Чистые башни, без нитей | ретракт ок | — |
| Тонкие нити-«паутина» | ретракт коротковат / температура высока | Прогнать [retraction](../retraction/), снизить температуру |
| Толстые сопли, капли на верхах | сильно высокая температура / ретракт почти не работает | температура вниз 5–10°C; проверить, что ретракт включён |

### Мост (наклонный или горизонтальный)

| Что видно | Причина | Действие |
| --- | --- | --- |
| Прямые ровные нитки, нет провисания | охлаждение и поток ок | — |
| Лёгкое провисание середины | охлаждение немного слабое | поднять fan на bridging до 100% |
| Спагетти, нитки болтаются | температура высокая, охлаждение слабое, скорость моста низкая | температура −5°C; bridge speed повыше; bridge fan 100% |
| Сорван мост (не схватился к опорам) | первые мостовые слои не приклеились | температура +5°C для первой нити моста |

### Нависы (overhangs)

| Что видно | Причина | Действие |
| --- | --- | --- |
| 30°: чисто. 45°: чисто. 60°: чисто. | принтер хорошо охлаждает | — |
| 30°: нормально. 45° / 60°: завитки, неровности | охлаждение слабое для крутых нависов | fan на 100%, снизить layer height |
| Уже на 30° провисает | температура высокая / охлаждение слабое | -5°C, fan +20%, прогнать [temperature-tower](../temperature-tower/) |

### Отверстия

| Что видно | Причина | Действие |
| --- | --- | --- |
| Круглые, размер ровный | ок | — |
| Меньше номинала на 0.05–0.15 мм | штатное поведение FDM | в Orca включить `XY hole compensation` |
| Овальные | вибрация / неравномерная скорость | снизить скорость / acceleration |

### Пины / маленькие башни

| Что видно | Причина | Действие |
| --- | --- | --- |
| Чёткие, не «снесло» | ок | — |
| «Сдулось» | температура высокая, перегрев в локальной точке | минимальное время слоя ↑ (Orca: `Slow down for cooling`) или уменьшить speed |

### Текст / надпись

| Что видно | Действие |
| --- | --- |
| Чёткий, читаемый | — |
| Размытый, заплывший | температура −5°C, скорость для мелких контуров ↓ |
