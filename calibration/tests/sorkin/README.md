# sorkin — диагностический плат «теста Соркина»

## Зачем

«Тест Соркина» — это **общий диагностический плат русской 3D-печатающей community**. На одной плоской детали собрано много мелких элементов разной геометрии: линии, окружности, отверстия, тонкие стенки, штифты, надписи, башенка с нависами. После печати его меряют штангенциркулем по референсным точкам и сравнивают с номиналом — это даёт картину **сразу по нескольким параметрам**: размерная точность, мелкая деталь, разрешение, обработка нависов.

Этот тест **дополняет**, а не заменяет XYZ-кубик и ortho-тест:

- XYZ-кубик: размеры по основным осям, общая геометрия.
- Ortho: перпендикулярность X / Y.
- **Sorkin: всё остальное** — мелкая деталь, отверстия, тонкие фичи на одном плате.

> Это не общепринятый тест на международных платформах вроде Printables. Авторская модель — из русскоязычного 3D-комьюнити. Источники сведены ниже; **проверь страницу автора и лицензию перед скачиванием**.

## Что обычно проверяет

В разных версиях платов фичи варьируются, но типичный набор:

- **Линии разной толщины** (от 0.2 до 1.0 мм с шагом 0.1) — проверка минимальной воспроизводимой толщины.
- **Отверстия разного диаметра** (например 1.0 / 2.0 / 3.0 / 5.0 мм) — точность и круглость дырок.
- **Штифты** соответствующих диаметров — обратная сторона теста: что принтер не «толстит» снаружи.
- **Тонкие стенки** разной высоты — проверка резонансов и стабильности.
- **Концентрические окружности** — однородность экструзии.
- **Маленькая башенка с нависами** разных углов — overhang test.
- **Надпись / шрифт** — мелкий рельеф.
- **Опорные размеры** (внешняя рамка известного размера) — повторная проверка XY.

## Что нужно

- **Инструменты:** **штангенциркуль (0.01 мм) — обязательно.** Желательно ещё мини-щуп / иголка для замера тонких отверстий.
- **Филамент:** PLA, контрастный к столу цвет (чтобы лучше видеть мелкие фичи).
- **Слайсер:** Orca-Flashforge, **стандартный** профиль (не «high quality», иначе тестируем не реальную печать, а специфический профиль).

## Откуда взять модель

- На **3dtoday.ru** — поиск по тегу **«тест Соркина»** или **«калибровочный тест»**. Топовые посты обычно с прикреплённым STL.
- Альтернативы на международных платформах с близким функционалом (если оригинал не нашёлся):
  - **Printables / Thingiverse** по запросу **«printer calibration plate»** или **«printer dimension test plate»**.
  - **«Maker's Muse Tolerance Test»** — отчасти похожий по идее (фичи на плоскости).
  - **«CHEP All-In-One Print Test»** — также комбинированный плат.

> Перед коммитом скачанной модели в эту папку — проверь лицензию автора и упомяни её в `<run>.md` записи. STL/3MF разрешены в репе для тестов калибровки (см. `.gitignore`).

## Как делать (методика)

1. Скачать модель, **запомнить номинальные размеры всех замеряемых фич** (обычно автор пишет в описании).
2. Нарезать в Orca-Flashforge стандартным профилем PLA.
3. Печатать на чистом стол в центре.
4. Дать остыть, снять, очистить.
5. По очереди замерить штангенциркулем все фичи, у которых есть номинал. Записать в таблицу.

## Как читать результаты

| Что замерил | Симптом | Что значит |
| --- | --- | --- |
| Тонкие линии | пропадают линии < 0.4 мм, остаются только толстые | минимальная воспроизводимая ширина = диаметр сопла; всё ниже — не для этого сопла |
| Отверстия | реальный диаметр меньше номинала | для отверстий это **нормально** — пластик «затягивается» внутрь по PA-эффекту; используй **XY hole compensation** в Orca |
| Отверстия | реальный диаметр меньше на 0.05–0.15 мм | штатное поведение, отметить как «−0.1» поправку в профиле |
| Отверстия | разный диаметр в разных направлениях (овал) | под-extrusion / скорость / pressure-advance — посмотреть [orthogonality](../orthogonality/) и [retraction](../retraction/) |
| Штифты | диаметр больше номинала | over-extrusion → прогнать [flow-rate](../flow-rate/) |
| Тонкие стенки | наклонены / нестабильны | вибрации; на стоке — снизить speed; кардинально — input-shaper после Klipper |
| Окружности | концентричные кольца «гуляют» по толщине | нестабильный поток или пробуксовка экструдера |
| Башенка с нависами | срыв / провисание на углах < 60° | охлаждение / температура — прогнать [temperature-tower](../temperature-tower/) |
| Надпись | размытая | температура высокая, или скорость высокая на мелком рельефе |
