# flow-rate — калибровка потока (Extrusion Multiplier)

## Зачем

Flow rate (он же **Extrusion Multiplier**, **EM**) — коэффициент, на который умножается «теоретическое» количество филамента, которое слайсер просит экструдер выдать. По умолчанию `1.0` (или 100%). На практике каждая катушка / экструдер имеют небольшое отклонение — катушка 1.74 мм вместо 1.75, шестерня экструдера чуть «гладит» филамент, etc. Если flow завышен — стенки толще номинала, слои «волосатые», верх «вспучен» (pillowing). Если занижен — щели на стенках, слабая адгезия.

Калибруется **на каждый филамент**.

## Что проверяет

- Толщину **одностенной** стенки относительно ожидаемой ширины линии.
- Качество **верхней** грани: должна быть гладкой, без щелей и не «вспученной».

## Два способа проверки

| Способ | Суть | Когда брать |
| --- | --- | --- |
| **Wall-thickness method** | печатаем одностенный куб, мерим толщину стенки штангенциркулем, сравниваем с заданной шириной линии в Orca | классика, простой и наглядный |
| **Top-surface method** (Orca) | печатаем кубик с верхней гранью, выбираем тот, где верх **самый гладкий** (без щелей, без вспучивания) | встроено в Orca-Flashforge, не нужен штангенциркуль |

В Orca-Flashforge встроены **обе** разновидности. Можно прогнать обе для подтверждения.

## Что нужно

- **Инструменты:** **штангенциркуль (0.01 мм)** для wall-thickness method.
- **Филамент:** с подобранной температурой ([temperature-tower](../temperature-tower/) сделан).
- **Слайсер:** Orca-Flashforge, `Calibration → Flow rate`.

## Откуда взять модель

В Orca-Flashforge:

1. `Calibration` → `Flow rate`.
2. Подменю предлагает **Coarse** (грубый, шаг 5%) и **Fine** (точный, шаг 1%) проходы.
3. Запустить **сначала Coarse**, выбрать лучший куб → потом **Fine** в окрестности этого значения.

## Как делать (методика)

### Этап 1 — Coarse (грубый)

1. `Calibration → Flow rate → Pass 1 (coarse)`.
2. Принтер печатает 5–9 кубов с разным flow (например `−10%, −5%, 0%, +5%, +10%`).
3. Дать остыть.
4. **Top-surface method:** найти куб с **самой гладкой** верхней гранью.
   - Слишком много flow → верх «вспучен», виден pillowing, проступают линии слоёв сквозь верх.
   - Слишком мало flow → щели между линиями верхней грани, видна «соломка».
   - Идеал → верх ровный, гладкий, без щелей и без вспучивания.
5. **Wall-thickness method (опционально):** замерить штангенциркулем толщину стенки. Сравнить с шириной линии в Orca (обычно `0.42 мм`):
   - Толщина стенки должна равняться `(line_width × 1) ± погрешность`.
   - Реально: `0.42 ± 0.02 мм` для `0.42 мм` line_width.

### Этап 2 — Fine (точный)

1. `Calibration → Flow rate → Pass 2 (fine)`.
2. Указать flow, который выбрал в coarse, как стартовое значение. Orca напечатает кубы вокруг с шагом 1%.
3. Снова выбрать лучший по top-surface методу.
4. Это и есть финальный flow для филамента.

## Как читать результат (детально)

| Признак на верхней грани | Что значит | Действие |
| --- | --- | --- |
| Гладкая, ровная, без видимых линий и щелей | оптимум | записать flow |
| Между линиями видны щели, виден infill | flow **низкий** | поднять flow на 1–2% |
| Линии сливаются в кашу, поверхность **вспучена**, видны бугры | flow **высокий** | снизить flow на 1–2% |
| По кругу краёв чисто, в центре пузыри/вспучивание | flow слегка высокий | снизить на 1% |

| Замер стенки (для wall-thickness) | Что значит |
| --- | --- |
| Толщина = line_width ± 0.02 | оптимум |
| Толщина > line_width на 0.05+ | over-extrusion |
| Толщина < line_width на 0.05+ | under-extrusion |

## Что записать

Файл `<filament-name>.md` по катушке.

Финальный flow → в **профиль филамента** в Orca:

`Filament → Edit → Filament settings → Flow ratio`.

Поля профиля филамента после полной калибровки PLA должны быть заполнены: `Nozzle temperature`, `Bed temperature`, `Flow ratio`, `Retraction length`. Это — основа для всех будущих печатей этой катушкой.
