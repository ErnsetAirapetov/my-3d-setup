# retraction — калибровка ретракта

## Зачем

Ретракт — это **обратное движение филамента** на короткое расстояние, когда сопло перестаёт печатать и переезжает к новой точке. Цель — **предотвратить капание** расплавленного пластика на «холостом» переезде. Если ретракт настроен плохо:

- Слишком короткий → сопло оставляет нити **между деталями или между башнями**.
- Слишком длинный → большой износ экструдера, риск **«размол» филамента** в шестернях, риск воздушных пробок в hotend.

Тест — на каждый филамент. Иногда — после смены сопла (диаметр меняет поведение).

## Что проверяет

- Минимальную длину ретракта, при которой исчезают stringing-нити.
- Косвенно — температуру (если все длины ретракта дают нити, проблема не в нём, а в температуре — иди в [temperature-tower](../temperature-tower/)).

## Что нужно

- **Инструменты:** глаза, нож (срезать остатки нитей перед оценкой).
- **Филамент:** PLA с **уже подобранной** температурой ([temperature-tower](../temperature-tower/) сначала!).
- **Слайсер:** Orca-Flashforge, встроенный генератор `Calibration → Retraction test`.

## Откуда взять модель

В Orca-Flashforge — **встроенно**:

1. `Calibration` → `Retraction test`.
2. Указать диапазон длины ретракта и шаг.

   **Стартовые диапазоны для 5M Pro (direct drive экструдер):**
   - **PLA:** 0.2 → 1.5 мм, шаг 0.1 мм.
   - **PETG:** 0.5 → 2.5 мм, шаг 0.2 мм.
   - **TPU:** 0.0 → 1.0 мм, шаг 0.1 мм (TPU вообще плохо ретрактится — лучше отключать).

3. Скорость ретракта на 5M Pro по умолчанию ~30–40 мм/с — оставить как в профиле машины.

> 5M Pro — **direct drive** (экструдер прямо над hotend), поэтому короткий ретракт. На принтерах с боуденом (трубка между экструдером и hotend) ретракт обычно 4–8 мм. **Не путать.**

## Как делать (методика)

1. **Сначала** убедиться, что температура подобрана в [temperature-tower](../temperature-tower/). Иначе калибруем не ретракт, а температуру.
2. В Orca-Flashforge: `Calibration → Retraction test`. Задать диапазон.
3. Orca генерирует **две колонны** на расстоянии. Принтер прыгает между ними; на каждом уровне — своя длина ретракта.
4. Печатать.
5. Дать остыть, **не срезать** нити до оценки.

## Как читать результат

Идём по уровням снизу вверх (обычно ретракт растёт с высотой):

| Что видно | Что значит |
| --- | --- |
| Толстые нити, капли пластика между колоннами | ретракт **слишком короткий**, на этой длине пластик не успевает уйти из сопла |
| Тонкая «паутина» нитей | ретракт почти достаточен, но не до конца |
| **Чистые колонны, ни одной нити** | оптимум |
| Дальше — ещё чище / то же самое | дальше увеличивать **смысла нет**, лишний износ экструдера |

Выбираем **минимальную длину**, на которой нитей **уже нет**, и записываем её в профиль филамента.

## Если все длины дают нити

Это значит проблема не в ретракте, а:

1. **Высокая температура** → температура → перепрогнать [temperature-tower](../temperature-tower/).
2. **Влажный филамент** (выкипает влага → пузыри → нити) → просушить, попробовать другую катушку.
3. **Засор сопла** или износ → почистить сопло, проверить ровность экструзии.

## Что записать

Файл по катушке `<filament-name>.md` в этой папке (по аналогии с temperature-tower).

Найденное значение → в **профиль филамента** в Orca:

`Filament → Edit → Filament settings → Retraction → Retraction length`.

Заметки на тип в общем виде — в [filaments/notes/](../../../filaments/notes/).
