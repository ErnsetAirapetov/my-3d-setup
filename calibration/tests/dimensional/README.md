# dimensional — размерная точность X / Y / Z

Проверка геометрии принтера независимо от филамента: масштаб осей, ортогональность, точность мелких фич. Делается один раз (на стоке уже пройдено).

## Что входит

- **XYZ-кубик 20 мм** (Thingiverse #1278865) — размеры по осям, общее качество.
- **Ortho-рамка 100×100** — перпендикулярность X↔Y по диагоналям.
- **Соркин / K3D Accuracy Test v8** — масштаб на длинном плече (до 145 мм), мелкие фичи.

Замеры — штангенциркулем 0.01 мм, по нескольку точек на ось, на полностью остывшей детали.

## Вердикт (stock, 2026-04-29)

- **X / Y масштаб — точны из коробки** (Side_X 99.99, Side_Y 100.00; steps/mm корректны).
- **Ortho — на грани нормы**, скос 0.17° (D1−D2 = 0.30 мм). Глазом не виден.
- **Z = +0.5%** (кубик 20.106 вместо 20.00) — steps/mm по Z завышен, на стоке не правится → **backlog для Klipper**.
- Тонкие фичи слегка недоливали → закрыто калибровкой [flow-rate](../flow-rate/).
