# calibration/tests/

Папка под отдельные калибровочные тесты. **На каждый тест — своя подпапка**, создаётся по факту выполнения, чтобы не плодить пустоту.

## Шаблон папки теста

```
tests/<test-name>/
├── README.md       # Описание: цель, условия, результаты, фото
├── model.stl       # STL/3MF используемой модели
└── photos/         # Фото результата (если нужны)
```

## Формат `README.md` теста

```markdown
# <test-name>

## Цель
<что проверяем и зачем>

## Источник модели
<ссылка на модель + автор/лицензия>

## Прогон 1 — YYYY-MM-DD

- Прошивка: stock | forge-x | klipper
- Филамент: <марка, тип, цвет, диаметр>
- Температура сопла / стола: <°C>
- Скорость / ускорения: <значения>
- Слайсер: OrcaSlicer, профиль <имя>

### Замеры
| Параметр | Ожидаемое | Фактическое | Δ |
| --- | --- | --- | --- |
| ... | ... | ... | ... |

### Выводы
<что не так, что менять>
```

Повторные прогоны теста (после апгрейда, мода или смены прошивки) добавляются как новые секции `## Прогон N — YYYY-MM-DD`, **не затирая** предыдущие — это даёт историю «до и после».
