# pressure-advance — PA

Компенсация давления в hotend: убирает наплывы в углах и узелки на шве. Делается на каждый филамент после flow.

## Как

Orca-Flashforge → `Calibration → Pressure advance`. Печатает паттерн с разным PA, выбрать значение с самыми чёткими углами без наплывов. Итог → `Filament → Pressure advance`.

## Результаты

### ESUN PLA+ — 2026-06

- **PA = 0.045** — чистейшие углы, убирает наплывы в углах и узелки на шве винта.

→ записано в профиль Orca и [filaments/notes/esun-pla-plus.md](../../../filaments/notes/esun-pla-plus.md).
