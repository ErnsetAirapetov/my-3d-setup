# temperature-tower — температура сопла

Подбор оптимальной температуры сопла под конкретную катушку. Делается на каждый новый филамент.

## Как

Orca-Flashforge → `Calibration → Temperature`. Для PLA диапазон 230 → 190 °C, шаг 5 °C. Печатает башню с впечатанным `M104` на каждом уровне. После остывания разломить по уровням, смотреть stringing, нависы и межслойную адгезию.

Оптимум — минимум нитей **И** прочная адгезия слоёв.

## Результаты

### ESUN PLA+ — 2026-06

- Холодный край (190–205 °C): слабое спекание, белёсые мостики.
- Горячий край: сопли (stringing).
- **Оптимум: 210 °C** (initial layer 215 °C).
