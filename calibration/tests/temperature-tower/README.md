# temperature-tower — температурная башня (под филамент)

## Зачем

Каждая катушка филамента имеет **свой оптимум температуры сопла**, который не совпадает ни с тем, что напечатано на этикетке (это диапазон), ни с тем, что в стандартном профиле слайсера. Башня позволяет **за одну печать перебрать диапазон 30–50°C** и выбрать конкретное значение для этой катушки.

Делается **на каждый филамент**, при первом знакомстве с ним. После — записывается в профиль филамента в Orca и в [filaments/notes/](../../../filaments/notes/).

## Что проверяет

На каждом «уровне» (5–10°C шагом) башни смотрим:

- **Stringing** между парными колоннами или внутри башни (нити пластика).
- **Качество нависов** на верхней грани каждого уровня.
- **Адгезию слоёв** (стенка башни должна быть монолитной, без щелей).
- **Bridging** (если в модели есть мост).
- **Surface finish** на стенках.

Лучший уровень → его температура = твой оптимум.

## Что нужно

- **Инструменты:** глаза, нож/кусачки чтобы разломить башню по уровням и посмотреть адгезию слоёв.
- **Филамент:** **по одному прогону на катушку.**
- **Слайсер:** Orca-Flashforge, **встроенный** генератор температурной башни (`Calibration → Temperature`).

## Откуда взять модель

В Orca-Flashforge — **встроенно**:

1. Открыть Orca-Flashforge.
2. Сверху меню `Calibration` → `Temperature`.
3. Выбрать тип филамента (PLA / PETG / ABS / TPU). Это задаёт стартовый и конечный диапазон.
4. Orca **сама** сгенерирует башню с впечатанной командой `M104 S<temp>` на каждом уровне.

> Никаких внешних STL не нужно. Папку всё равно создаём — для записей прогонов.

Альтернатива (если хочется руками): «Smart Temperature Tower» от gaaZolee на Thingiverse / Printables, нарезать через post-processing скрипт. Но для старта — Orca встроенно проще.

## Как делать (методика)

1. Загрузить катушку, дождаться, пока филамент стабильно идёт через сопло (несколько свободных экструзий).
2. В Orca-Flashforge: `Calibration → Temperature` → выбрать тип филамента → выбрать диапазон.

   **Стартовые диапазоны:**
   - **PLA:** 230 → 190°C (шаг 5–10°C).
   - **PETG:** 250 → 220°C.
   - **ABS / ASA:** 260 → 230°C.
   - **TPU:** 230 → 210°C.

3. Если профиль филамента в Orca уже есть — оставить **остальные** настройки **по умолчанию** (скорость, охлаждение). Мы тестируем температуру, не профиль.
4. Нарезать, отправить на принтер, печатать.
5. После остывания — **аккуратно сломать** башню по границам уровней (или разрезать), чтобы посмотреть адгезию между слоями каждого уровня.

## Как читать результат

Идём по уровням (от высокой температуры внизу к низкой наверху, обычно):

| Уровень / температура | На что смотреть |
| --- | --- |
| Сильное stringing, кончик сопла «капает» | температура **слишком высокая** для этой катушки |
| Лёгкие нити, стенка глянцевая, поток лёгкий | условный «верх» оптимального диапазона |
| **Чистые стенки, минимум нитей, чёткие углы, хорошие нависы** | **оптимум** |
| Стенка матовая, поверхность шероховатая, видны линии слоёв | условный «низ» оптимума |
| При попытке сломать — **слои легко отделяются** | температура **слишком низкая** — плохая межслойная адгезия |
| Под-extrusion, пропуски на стенке, треск экструдера | температура слишком низкая, пластик не успевает плавиться |

Выбираем уровень с **лучшим балансом**: минимум stringing-а **И** хорошая межслойная адгезия. Если есть конфликт (на низкой температуре нет нитей, но плохая адгезия) — берём середину и доделываем через [retraction](../retraction/).

## Что записать

В этой папке создать файл `<filament-name>.md` (по одному на катушку). Внутри:

- Бренд / тип / цвет филамента.
- Дата прогона.
- Диапазон, который тестировал.
- Найденная оптимальная температура.
- Заметки: на какой высоте появлялись stringing / плохая адгезия.
- Фото башни с пометками уровней.

Найденную температуру **записать в профиль филамента** в Orca-Flashforge (`Filament → Edit → Filament settings → Nozzle temperature`).

Также скопировать ключевые наблюдения в [filaments/notes/<тип>.md](../../../filaments/notes/) для общих заметок по этому типу пластика.

## Шаблон записи

```markdown
## Прогон — <бренд / тип / цвет филамента> — YYYY-MM-DD

- Прошивка: v3.2.7
- Диапазон башни: <от>°C → <до>°C, шаг <step>°C
- Скорость / охлаждение: <по профилю>

### Наблюдения по уровням

| °C | Stringing | Нависы | Адгезия слоёв | Surface |
| --- | --- | --- | --- | --- |
| 230 | сильно | плохие | ок | шерох. |
| 220 | средне | ок | ок | гл. |
| 210 | мало | ок | ок | гл. |
| 200 | нет | ок | плохая | мат. |
| 190 | нет | ок | плохая | под-extr. |

### Оптимум: **<°C>**

### Фото
![tower](photos/tower.jpg)

### Выводы
<...>
```
