## Замеры

Стороны меряны между внутренними гранями посадочных площадок (это и есть эталон 100×100 в CAD). Диагонали — между внешними угловыми точками площадок (отсюда абсолютное значение ~143, а не 141.42 — это нормально, стороны и диагонали меряны по разным базам).

### Стороны (эталон 100.00 мм)

| Параметр | Значение, мм | Δ от 100.00 |
| --- | --- | --- |
| Side_X | 99.99 | −0.01 |
| Side_Y | 100.00 | 0.00 |

→ Масштаб X/Y буквально один в один. Steps/mm на X и Y откалиброваны идеально из коробки.

### Диагонали

| Параметр | Значение, мм |
| --- | --- |
| D1 | 143.23 |
| D2 | 142.93 |
| **D1 − D2** | **0.30** |

Угловое отклонение при сторонах 100×100:
```
ε ≈ ΔD / side = 0.30 / 100 = 0.003 рад ≈ 0.17°
```

## Интерпретация

| `D1 − D2` | Вердикт |
| --- | --- |
| < 0.30 мм | ortho ок, идти дальше |
| 0.30–0.70 мм | малый скос, чаще ремень |
| > 0.70 мм | существенный, проверять раму |

**Фактический вердикт: на границе «ок» и «малый скос» (0.30 мм ровно, 0.17°).** Глазом на печати не виден. Опционально проверить натяжение ремней (ровный «басовый» звук при щелчке); если ремни нормальные — это просто заводская точность стока, живём с этим.
