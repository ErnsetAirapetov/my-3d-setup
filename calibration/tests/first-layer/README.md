# first-layer — тест первого слоя (squish)

## Зачем

Первый слой — **фундамент** любой печати. Если он плохо лежит, выше по стопке расти нечему: ни XYZ-кубик не сделать, ни температурную башню. Поэтому это первый тест после распаковки и любой смены стола / сопла / филамента.

В Orca-Flashforge **отдельного пункта меню для squish-теста нет** — он делается на отдельной модели первого слоя + ручной подстройкой Z-offset на принтере во время печати.

## Что проверяет

- Правильный Z-offset (зазор между соплом и столом).
- Адгезию по всей площади стола (не только в центре).
- Что auto-bed-leveling реально снял корректную карту.
- Что стол не перекошен по углам — нужен ли механический re-level.

## Что нужно

- **Инструменты:** глаза, можно лупу. Штангенциркуль не нужен.
- **Филамент:** PLA (он самый прощающий, ровно ложится).
- **Слайсер:** Orca-Flashforge, любой профиль с высотой слоя `0.2 мм`.
- **Время:** 5–10 минут на прогон.

## Откуда взять модель

Подойдёт любая из категории **«first layer test pattern 200×200»**. Хорошие варианты:

- На Printables по запросу **«first layer test 200x200»** — выбрать самую популярную (обычно зигзаг/спираль на всю площадь, 1 слой, без infill).
- Классический **«Bed Level Test Square»** на Thingiverse — пять квадратов: четыре по углам, один в центре. Каждый на 1 слой.
- Можно **самому сгенерировать в Orca-Flashforge:** добавить квадрат `200×200×0.2 мм`, infill 100%, layer height = 0.2 мм, perimeters 0, infill pattern «concentric» или «aligned rectilinear». Один слой и всё.

> Скачанную модель сложить рядом с этим README в этой же папке. Калибровочные STL коммитим в репу — `.gitignore` для них сделано исключение.

## Как делать (методика)

1. **Подготовка стола.** Если стол грязный — протереть IPA. Не трогать рабочую поверхность пальцами.
2. **Auto-bed-leveling.** Запустить на принтере (меню → Level), дождаться завершения.
3. **Запуск печати.** Положить модель в Orca, нарезать, отправить на принтер.
4. **Live-наблюдение.** Не отходить во время первого слоя. На сенсорном экране принтера крутить **Z-offset** (он же `zAxisCompensation` в `/detail`) **прямо во время печати**:
   - Шаг подстройки: `0.025 мм` (или `0.05` для грубой коррекции).
   - Минус — сопло опускается ближе к столу (больше squish).
   - Плюс — поднимается дальше от стола (меньше squish).
5. **Дать линиям остыть** перед оценкой и снятием.

## Как читать результат

Гляди на качество линий по всей площади:

| Симптом | Что значит | Действие |
| --- | --- | --- |
| Чёткие отдельные «нитки», между ними щели — стол просвечивает | сопло слишком высоко, недостаточно squish | Z-offset → **минус** на 0.05 мм, перепечатать |
| Линии прозрачные, размазанные, неровные, сопло иногда «царапает» | сопло слишком низко, перетянутый squish | Z-offset → **плюс** на 0.05 мм |
| Слегка сплюснутые соседние линии **сливаются** в сплошную плёнку, без щелей и прозрачности | оптимум | Запомнить значение Z-offset, записать |
| В центре всё хорошо, по углам щели или отрыв | стол перекошен по углам, auto-bed-leveling не справляется | Покрутить винты под столом / re-level вручную, повторить auto-leveling, перепечатать |
| По всей площади то лучше, то хуже неравномерно | стол с волной (рельеф) | Снять [bed-mesh](../../bed-mesh/), посмотреть карту; если кривизна большая — менять стол |

## Что записать после прогона

Создать в этой папке файл `<YYYY-MM-DD>-prog<N>.md` (или единый `runs.md` с секциями) и в нём:

- Дата прогона.
- Прошивка (`v3.2.7` сейчас).
- Филамент (бренд, тип, цвет).
- Температура сопла / стола.
- Найденное значение Z-offset (`zAxisCompensation`).
- Фото первого слоя в нескольких точках стола.
- Выводы.

После того как нашёл правильный Z-offset — **записать его в профиль машины в Orca** (или сохранить как стартовое значение, если принтер хранит сам).
