# first-layer — Z-offset (squish)

Фундамент любой печати. Делается после распаковки и после смены стола / сопла.

## Как

Печатать плоскую модель «first layer test 200×200» (Printables) или квадрат 200×200×0.2 в Orca. Перед печатью — Auto Leveling на принтере. Во время первого слоя крутить **Z-offset** (`zAxisCompensation`) прямо на экране, шаг 0.025 мм:

- минус → ближе к столу (больше squish);
- плюс → дальше (меньше squish).

Оптимум — соседние линии сливаются в сплошную плёнку без щелей и без прозрачности. Если центр ок, а углы отрываются — стол перекошен, ровнять винтами под платформой.

## Результаты

Z-offset подобран, первый слой стабильный. Значение хранит сам принтер (`zAxisCompensation`).
