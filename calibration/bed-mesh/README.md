# calibration/bed-mesh/

Снимки и заметки по карте высот стола (bed mesh).

## Статус на стоковой прошивке (v3.2.7)

**Сырая карта высот недоступна.** Flashforge auto-leveling делает probing «под капотом» и применяет компенсацию сам, но пользователю не отдаёт ни через UI, ни через API. На принтере есть только бинарный пункт «Auto Leveling» — запустить и довериться.

Что было проверено 2026-04-28 (см. [журнал](../../journal/2026-04-28-stage1-and-mesh-probing.md)):

| Канал | Команда | Ответ |
| --- | --- | --- |
| TCP 8899 | `~M420 V`, `~M420`, `~M421` | принимает, отвечает `ok`, **данных не печатает** |
| TCP 8899 | `~M503`, `~M501` (EEPROM-report) | `ok`, без вывода |
| TCP 8899 | `~M661` (file list) | список `.gcode/.3mf` в `/data/`, **меш-файла там нет** |
| HTTP 8898 | `POST /product` | управляемые параметры: свет, два вентилятора, температура сопла/стола. **Меш не входит.** |
| HTTP 8898 | `POST /detail` | живые температуры, прогресс печати, `zAxisCompensation`. **Меш-сетки нет.** |

Вывод: на стоке мы можем влиять только на **глобальный Z-offset** (`zAxisCompensation`), а не на 5×5 / 7×7 точечную компенсацию. Снять и сохранить полноценный меш получится только после Forge-X / Klipper.

## Что делать сейчас (стоковая прошивка)

1. Перед калибровочными тестами этапа 2 — запустить **Auto Leveling** из меню принтера. Этого достаточно как «текущая карта применена», даже если мы её не видим.
2. Подобрать **Z-offset** через [tests/first-layer/](../tests/first-layer/) и записать значение в профиль Orca + в журнал. Это единственный «мешеобразный» параметр, который тут реально настраивается.
3. Если тест первого слоя показывает разницу адгезии «центр vs углы» — значит auto-leveling не справляется (стол с волной или перекосом). Тогда **механически** ровнять стол по углам (винты под платформой) и повторять. Это и есть наш «меш на стоке».

## Что делать после Klipper

После перехода на Klipper здесь будет жить:

- Скриншоты карты из Mainsail/Fluidd (`BED_MESH_CALIBRATE` → веб-визуализация).
- Экспортированные `.cfg` секции `[bed_mesh default]`.
- Заметки: дата, температура стола при снятии, что делал перед.

### Шаблон записи (для Klipper-эпохи)

```markdown
## YYYY-MM-DD — <короткая тема>

- Прошивка: klipper <версия>
- Температура стола: <°C>
- Что делал перед снятием: <выравнивание по углам / ничего / поменял пружины / ...>
- Точки сетки: <NxM>

![mesh](mesh-YYYY-MM-DD.png)

### Выводы
<что видно, какие действия по итогу>
```

История важна — именно по ней понятно, как ведёт себя стол при разных условиях и улучшается ли ситуация после действий.
