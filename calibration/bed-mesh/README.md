# calibration/bed-mesh/

Карта высот стола.

## Стоковая прошивка (v3.2.7)

**Сырой меш недоступен.** Flashforge делает probing под капотом и применяет компенсацию сам, но не отдаёт ни через UI, ни через API (проверено 2026-04-28: `M420/M421`, `M503`, `/product`, `/detail` — меш-данных не дают).

Что доступно на стоке:

1. **Auto Leveling** из меню принтера перед печатью — «карта применена», даже если её не видно.
2. Глобальный **Z-offset** (`zAxisCompensation`) — см. [first-layer](../tests/first-layer/).
3. Если адгезия «центр vs углы» разная — ровнять стол винтами под платформой.
