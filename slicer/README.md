# slicer/ — профили слайсера

## Выбор слайсера: **OrcaSlicer**

Принят как основной по причинам:
- Универсальный, активно развивается, большое community.
- Отлично интегрируется с Klipper (отправка через Moonraker, нативная поддержка PA / IS).
- Встроенные калибровочные тесты (PA, flow, max volumetric speed, retraction) прямо из меню.
- Поддерживает профили под Flashforge через сообщество (плюс есть форк Orca-Flashforge, при необходимости можно подсмотреть оттуда настройки машины).

Альтернативы держим в уме на будущее:
- **Orca-Flashforge** — официальный форк под Flashforge, может пригодиться как источник стартового профиля 5M Pro.
- **PrusaSlicer / SuperSlicer** — если что-то понадобится специфическое.

## Структура

| Папка | Что внутри |
| --- | --- |
| [machine/](machine/) | Профили принтера. Под разные стадии: stock vs Klipper, разные сопла. |
| [filament/](filament/) | Профили филаментов: PLA, PETG, ABS, TPU, конкретные марки. |
| [profiles/](profiles/) | Process-профили (печать): качество, скорость, поддержки, варианты под задачи. |

## Как работаем

- Любая ручная правка в OrcaSlicer → экспорт обновлённого профиля сюда → коммит.
- Профиль именуется так, чтобы было понятно стадию и задачу: `5m-pro_stock_0.4mm.json`, `5m-pro_klipper_0.4mm.json`, `pla_generic_220.json`.
- В коммитах указывать, что изменилось и почему.

## Подключение к принтеру

- На стоке: отправка через приложение Flashforge / напрямую G-code через USB / SD.
- На Klipper: через Moonraker (URL принтера в настройках OrcaSlicer).
- Поток с камеры в OrcaSlicer (если поддерживает) — `http://192.168.1.134:8080/?action=stream`.
