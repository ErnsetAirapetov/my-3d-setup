# slicer/profiles/

Process-профили (профили печати) для OrcaSlicer. Описывают **как** печатать: высота слоя, плотность заполнения, поддержки, walls, и т.д.

Имя файла: `<задача>_<сопло>_<высота-слоя>.json`, например:
- `quality_0.4mm_0.16mm.json` — медленный качественный.
- `standard_0.4mm_0.20mm.json` — сбалансированный.
- `draft_0.4mm_0.28mm.json` — быстрый драфтовый.
- `mini_0.4mm_0.12mm.json` — мелкая детализация.

Профили рассчитаны для конкретных профилей машины и филамента. Связи прописываем в `README.md` каждого профиля.
