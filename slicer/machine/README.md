# slicer/machine/

Профили принтера для OrcaSlicer.

Один профиль — один файл. Имя должно отражать стадию и конфигурацию: например `5m-pro_stock_0.4mm.json`, `5m-pro_klipper_0.4mm.json`, `5m-pro_klipper_0.6mm.json`.

Параметры, которые влияют на профиль машины: размер рабочего поля, диаметр сопла, max скорости/ускорения, start/end G-code, прошивка (Marlin/Klipper).
