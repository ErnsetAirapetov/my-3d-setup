# Архитектура опенсурс-стека — полная карта

Наглядное «что где работает, почему именно там, как ставится и подключается». Это **референс-картина**
всей системы. Пошаговый план сборки и бюджет памяти — в [STACK.md](STACK.md). Роль и спеки CB1 —
в [mods/planned.md](mods/planned.md). Сетевые координаты — в [printer/network.md](printer/network.md).

---

## TL;DR — одна мысль

Два устройства. **Принтер — тонкий** (только управление: Klipper + Moonraker, без лишнего, ради
128 МБ RAM). **CB1 — толстый сервер 24/7** (весь удобный обвес: Telegram-бот, учёт филамента,
удалёнка, уведомления). Всё общается через **Moonraker API принтера**. Камера — пока встроенная в
принтер.

```
                              ☁ ИНТЕРНЕТ
                                  │
                  Telegram  ◄─────┤─────►  Tailscale VPN
                  (бот)           │        (доступ из любой точки)
                                  │
   ┌──────────────────────────────┼──────────────────────────────────┐
   │ 🏠 ДОМАШНЯЯ СЕТЬ  OpenWRT-роутер 192.168.1.1                      │
   │                              │                                    │
   │   ┌──────────────────────┐   │   ┌──────────────────────────┐     │
   │   │ 🖨  ПРИНТЕР AD5M Pro  │   │   │ 🧠 CB1  (сервер 24/7)    │     │
   │   │ 192.168.1.133        │◄──┴──►│ 192.168.1.135            │     │
   │   │ ТОНКИЙ — 128 МБ      │ LAN   │ ТОЛСТЫЙ — 1 ГБ           │     │
   │   │                      │ API   │                          │     │
   │   │ Forge-X (Headless):  │       │ • Telegram-бот           │     │
   │   │  • Klipper (klippy)  │       │ • Spoolman (филамент)    │     │
   │   │  • Moonraker  :7125  │◄──────┤ • Mobileraker-companion  │     │
   │   │  • Mainsail   :80    │ забор │ • Tailscale (subnet)     │     │
   │   │  • камера     :8080  │ данных│ • таймлапсы (рендер тут) │     │
   │   │  • KAMP, макросы     │       │ • git-бэкапы конфигов    │     │
   │   └──────────────────────┘       └──────────────────────────┘     │
   │            ▲                              ▲                        │
   └────────────┼──────────────────────────────┼────────────────────────┘
                │                              │
          💻 ПК (OrcaSlicer,            📱 Телефон (Mobileraker,
             браузер → Mainsail)           браузер, Telegram)
```

## Два устройства — за что отвечают

| | 🖨 Принтер AD5M Pro | 🧠 CB1 (сервер) |
| --- | --- | --- |
| Железо | Allwinner T113-S3, **128 МБ RAM** | Allwinner H616 4×A53, **1 ГБ RAM** |
| Роль | **контроллер**: двигает моторы, греет, режет g-code | **сервер удобства**: всё, что не критично к моторам |
| Принцип | минимум софта → максимум свободной RAM | тут живёт весь «фарш» |
| Включён | когда печатаем | **всегда** (24/7) |
| Сеть | `192.168.1.133` (есть) | `192.168.1.135` (зарезервировать на роутере) |

> Почему так делят: память принтера (128 МБ) **впаяна и не расширяется**. Любой лишний сервис на
> принтере — риск вылета печати. CB1 с 1 ГБ берёт всё тяжёлое на себя и общается с принтером по сети.
> Подробнее про лимит RAM — [STACK.md §0](STACK.md#0-реальность-про-память--читать-первым).

## Полная карта компонентов

«Где» = на каком устройстве крутится процесс. «Почему там» — главное, что надо понять.

| Компонент | Что делает | Где | Почему именно там | Как общается |
| --- | --- | --- | --- | --- |
| **Klipper (klippy)** | мозг управления: кинематика, температуры, g-code | 🖨 принтер | обязан быть рядом с MCU — управляет моторами в реальном времени | внутренний serial → MCU; наружу — API-сокет |
| **MCU-прошивка** | реалтайм: шаги моторов, ШИМ нагрева | 🖨 принтер (чип MCU) | это само железо движения | внутренний serial ↔ klippy |
| **Moonraker** | API-шлюз: через него ходят ВСЕ (UI, бот, сервисы) | 🖨 принтер | должен локально говорить с klippy; сам лёгкий | слушает порт **7125**, к нему коннектятся все клиенты |
| **Mainsail** | основной веб-интерфейс | 🖨 принтер | идёт в комплекте Forge-X; статика, лёгкий | браузер → порт **80**, данные берёт из Moonraker :7125 |
| **Fluidd** | альтернативный веб-интерфейс | 🖨 принтер | в комплекте; запасной UI на вкус | браузер → Moonraker :7125 |
| **ustreamer (камера)** | MJPEG-поток со встроенной камеры | 🖨 принтер | камера физически воткнута в плату принтера | отдаёт поток на порт **8080** |
| **KAMP** | адаптивный bed mesh + умная очистка сопла | 🖨 принтер | это конфиг/макросы Klipper, почти ноль RAM | работает внутри Klipper |
| **Макросы** (START/END_PRINT и т.д.) | сценарии старта/конца печати | 🖨 принтер | часть `printer.cfg` | внутри Klipper |
| **Telegram-бот** (`moonraker-telegram-bot`) | статус печати, фото, кнопки управления, уведомления, таймлапсы | 🧠 CB1 | нужен стабильный интернет; рендер таймлапса тяжёлый — не на принтере | к Moonraker принтера :7125 + камере :8080; наружу к Telegram |
| **Spoolman** | учёт филамента (катушки, остатки, расход) | 🧠 CB1 | в FAQ Forge-X помечен «resource-intensive» — на 128 МБ не место | Moonraker принтера → Spoolman :7912 |
| **Mobileraker-companion** | push-уведомления для мобильного приложения | 🧠 CB1 | отдельный сервис, удобнее на сервере 24/7 | к Moonraker принтера :7125 |
| **Tailscale** | удалёнка из интернета (VPN-меш) | 🧠 CB1 | всегда включённый шлюз; раздаёт доступ ко всей сети | subnet router: анонс `192.168.1.0/24` |
| **Таймлапсы** | видео сборки модели | 🧠 CB1 (через бот) | рендер ffmpeg тяжёлый — делаем на CB1, не на принтере | бот забирает кадры с камеры :8080, рендерит у себя |
| **git-бэкапы** | резерв конфигов принтера | 🧠 CB1 | сервер 24/7 удобен для бэкапов по расписанию | тянет конфиги через Moonraker/SSH |
| **OrcaSlicer** | слайсер: модель → g-code → отправка | 💻 ПК | тяжёлый desktop-софт, место ему на ПК | загрузка печати через Moonraker :7125 |
| **Mobileraker** (приложение) | управление с телефона | 📱 телефон | нативное приложение | к Moonraker :7125 (дома напрямую, извне — через Tailscale) |

## Диаграмма 1 — физика и сеть (кто куда воткнут)

```
   ☁ ИНТЕРНЕТ (провайдер)
        │
   ┌────┴─────────┐
   │ OpenWRT      │  192.168.1.1
   │ роутер       │
   └─┬──────────┬─┘
     │ Ethernet │ Ethernet/Wi-Fi
     │          │
 ┌───┴────┐  ┌──┴───────────┐
 │ ПРИНТЕР│  │ CB1 + PI4B   │
 │ .133   │  │ .135         │
 │        │  │              │
 │ камера │  │ [microSD]←── ОС грузится отсюда
 │ (USB,  │  │ [USB-C]  ←── питание 5.1V/3A
 │  встр.)│  │ [RJ45]   ←── в роутер
 └────────┘  │ [радиатор]   │
             └──────────────┘
     ▲              ▲
     │ Wi-Fi/LAN    │ Wi-Fi/LAN
  ┌──┴───┐       ┌──┴────┐
  │  ПК  │       │телефон│
  └──────┘       └───────┘
```

Физически CB1 не соединяется с принтером проводом — **только через роутер по сети**. Это важно:
никакой пайки, никакого USB между ними.

## Диаграмма 3 — потоки данных (три сценария)

**A. Печать с ПК (дома):**
```
OrcaSlicer (ПК) ──g-code──► Moonraker :7125 (принтер) ──► klippy ──► MCU ──► моторы
```

**B. Управление с телефона из интернета (например, на работе):**
```
Mobileraker (телефон) ──► Tailscale ──► CB1 (subnet router) ──► Moonraker :7125 (принтер)
   видишь интерфейс и камеру так, будто ты дома — без проброса портов
```

**C. Уведомление в Telegram «печать завершена» + фото:**
```
klippy (событие) ──► Moonraker :7125 ──► Telegram-бот (CB1) ──┬──► берёт фото с камеры :8080
                                                              └──► шлёт в Telegram ──► 📱 тебе
```

## Сетевые порты (шпаргалка)

| Устройство | Порт | Сервис | Кто стучится |
| --- | --- | --- | --- |
| 🖨 принтер `.133` | 7125 | Moonraker (API) | Mainsail, бот, Spoolman, Mobileraker, OrcaSlicer |
| 🖨 принтер `.133` | 80 | Mainsail (веб) | браузер |
| 🖨 принтер `.133` | 8080 | ustreamer (камера) | браузер, Telegram-бот |
| 🖨 принтер `.133` | 22 | SSH | ты (настройка) |
| 🧠 CB1 `.135` | 7912 | Spoolman | Moonraker принтера |
| 🧠 CB1 `.135` | 22 | SSH | ты (настройка) |
| 🧠 CB1 `.135` | — | Telegram-бот, Tailscale | только исходящие, входящих портов не нужно |

> После Forge-X стоковые порты принтера (8898 REST, 8899 M-code) относятся к **стоковому** режиму
> dual-boot. В режиме мода управление идёт через Moonraker/Mainsail.

## Питание и физическое подключение CB1 (по шагам, для первого раза)

Никогда раньше не работал с такими платами — поэтому по пунктам и без сокращений:

1. **microSD — это «жёсткий диск» CB1.** Своей памяти у него нет. На карту записываем образ ОС с
   ПК, вставляем в слот на плате-носителе PI4B Adapter. Без карты CB1 не включится.
2. **Питание — только через разъём USB-C на PI4B Adapter.** Нужен блок **5V/3A (15 Вт)**.
   - ⚠️ **НЕ** питать от USB-порта ПК или от принтера — там не хватит тока, CB1 будет случайно
     перезагружаться и портить карту.
   - ⚠️ **НЕ** брать дешёвый «зарядник 1А/2А» — то же самое, просадки и перезагрузки.
   - ✅ Самый надёжный вариант — **официальный блок Raspberry Pi 4 (5.1V/3A, USB-C)**: он рассчитан
     ровно на эту форму платы и даёт чуть выше 5V, чтобы компенсировать потери в кабеле.
3. **Сеть — патч-корд Ethernet** из разъёма RJ45 на PI4B Adapter в свободный порт роутера. Можно и
   Wi-Fi (2.4 ГГц встроен), но провод стабильнее. CB1 работает на 100 Мбит — этого с запасом.
4. **Охлаждение** — радиатор уже стоит (был в комплекте). Корпус опционален (можно напечатать).
5. Включение: вставил карту → воткнул Ethernet → подал питание. Через ~1 минуту заходишь по **SSH**
   с ПК (логин по IP, который выдаст роутер). Монитор/клавиатура **не нужны** — всё headless.

Точные модели и спеки для покупки — в [tools/shopping-list.md §8](tools/shopping-list.md).

## Порядок установки (обзор; детально — в [STACK.md](STACK.md))

1. **Принтер:** бэкап стока → прошить Forge-X (Headless) → проверить Mainsail по LAN.
2. **Принтер:** обязательная пост-настройка (z-offset, bed mesh, g-code в Orca), калибровки.
3. **CB1:** записать ОС на microSD → в сеть → SSH → обновить.
4. **CB1:** Tailscale (удалёнка) → Telegram-бот → Spoolman → Mobileraker-companion.
5. **Клиенты:** OrcaSlicer (профиль Moonraker), Mobileraker на телефон, бот в Telegram.

Этапы 1–2 уже дают рабочий Klipper с веб-интерфейсом и камерой по LAN. CB1 (3–4) добавляет
Telegram-бота, удалёнку и учёт филамента.

## Почему так, а не иначе (обоснования)

- **Почему Moonraker остаётся на принтере, а не на CB1?** Moonraker обязан локально общаться с
  klippy. Вынести его на CB1 технически можно (проброс сокета по сети), но это хрупко и ломает
  OTA-обновления Forge-X. А сам Moonraker лёгкий — выносить его смысла мало. Разгрузку даёт
  выключение экрана и тяжёлых сервисов, а не перенос Moonraker.
- **Почему Telegram-бот на CB1, а не на принтере?** Боту нужен стабильный интернет и он рендерит
  таймлапсы (ffmpeg — тяжело). На 128 МБ это риск. На CB1 — спокойно.
- **Почему камера пока на принтере?** Встроенная камера физически воткнута в плату принтера. Чтобы
  вынести стрим на CB1 (ноль нагрузки на принтер + лучше качество), нужна отдельная USB-вебка — это
  осознанно отложено (см. ниже).
- **Почему Tailscale, а не проброс портов?** Проброс портов наружу — это дыра в безопасности
  (твой принтер виден всему интернету). Tailscale делает приватный шифрованный туннель: снаружи
  ничего не открыто, а ты заходишь как будто из дома.

## Что осознанно отложено

| Что | Почему отложено | Когда вернуться |
| --- | --- | --- |
| USB-вебка на CB1 | сейчас хватает встроенной; докупка позже | когда захочется лучше качество и совсем разгрузить принтер |
| Self-hosted Obico (AI-детект брака) | Tailscale уже закрывает удалёнку; Obico — тяжёлый | если захочется AI-обнаружение «спагетти» |
| Вынос Moonraker на CB1 | хрупко, ломает OTA | вряд ли понадобится |
| Перепайка SoC на 256 МБ | экстремальный ремонт | не планируется |
