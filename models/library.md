# Библиотека моделей

Лог скачанных и использованных моделей. **Сами файлы в репу не кладём** — храним только ссылки и заметки.

## Шаблон записи

```markdown
## <Название модели>

- **Автор:** <ник>
- **Источник:** <ссылка>
- **Лицензия:** <CC-BY / CC-BY-SA / CC-BY-NC / коммерческая / ...>
- **Дата скачивания:** YYYY-MM-DD
- **Назначение:** <зачем нужно>
- **Заметки:** <особенности модели, как ориентировать, нужны ли поддержки>
```

## Источники моделей

| Площадка | Особенности |
| --- | --- |
| [Printables](https://www.printables.com/) | Большой пул бесплатных моделей, конкурсы, активное community. |
| [MakerWorld](https://makerworld.com/) | Площадка от Bambu Lab, много готовых 3MF с настройками. |
| [Thingiverse](https://www.thingiverse.com/) | Старейшая, много моделей разного качества, лицензии — внимательнее. |
| [Cults3D](https://cults3d.com/) | Микс бесплатных и платных. |
| [Thangs](https://thangs.com/) | Поиск по моделям, агрегатор. |
| [GrabCAD](https://grabcad.com/) | Скорее инженерные/CAD модели. |
