# journal/ — хронологический дневник

Лента работ по принтеру: что делал, что заметил, что запланировал. Низкий порог входа — пиши коротко, не разбирая по «правильным» папкам.

## Формат

- Один файл — один день или одна сессия работы.
- Имя: `YYYY-MM-DD-краткая-тема.md` (например, `2026-04-26-setup.md`, `2026-05-03-first-klipper-boot.md`).
- Внутри — свободная форма: что сделал, что не получилось, на что обратить внимание в следующий раз.

## Зачем

Через месяц-два уже не вспомнишь, почему PA = 0.04, и в каких условиях прошёл первый удачный PETG. Дневник закрывает эту память.
