## Зондирование bed-mesh API стоковой прошивки

Пользователь не нашёл в стоковом UI принтера данные по карте высот. Цель — проверить, можно ли получить меш через TCP/HTTP API.

### Что попробовали

TCP `8899` (M-команды):

| Команда | Цель | Результат |
| --- | --- | --- |
| `~M420 V` | вывести таблицу меша (Marlin) | `Received. ok` — без вывода |
| `~M420` | то же без флагов | `ok` |
| `~M421` | get/set точки меша | `ok` |
| `~M503`, `~M501` | EEPROM-report со всеми настройками | `ok`, без вывода |
| `~M601` | запрос «control» (FF-специфичный) | `Control Success V2.1. ok` — переводит в control-режим, меш не отдаёт |
| `~M661` | список файлов в `/data/` | список `.gcode/.3mf` пользовательских файлов; **меш-файла там нет** |

HTTP `8898`:

| Эндпоинт | Что искали | Результат |
| --- | --- | --- |
| `POST /detail` | поле с массивом меша | в схеме нет — есть только `zAxisCompensation` (глобальный Z-offset) |
| `POST /product` | флаг управления компенсацией | управляются только: свет, два вентилятора, температуры сопла/стола |

### Вывод

**На стоке v3.2.7 сырая карта высот недоступна вообще.** Flashforge auto-leveling делает probing внутри и применяет компенсацию сам, но наружу (ни в UI, ни в API, ни в файлах) её не отдаёт. Из «меше-подобных» рычагов остаётся только глобальный `zAxisCompensation` (тот же, что подбирается тестом первого слоя).

Полноценный bed-mesh с визуализацией мы получим после Klipper. До тех пор:
1. Перед калибровочными прогонами — запускать Auto Leveling из меню принтера.
2. Подбирать Z-offset через [calibration/tests/first-layer/](../calibration/tests/first-layer/).
3. Если first-layer показывает разницу адгезии «центр vs углы» — механически крутить винты под платформой.

Зафиксировано в [calibration/bed-mesh/README.md](../calibration/bed-mesh/README.md).

## По «теста в Orca нет первого слоя»

В меню `Calibration` слайсера — Temperature, Flow rate, Pressure advance, Retraction test, Max flowrate, Cornering, Tutorial. **Это всё этапы 3 и 5** (под филамент и Klipper). First-layer туда не входит и не может входить — он про геометрию принтера, не про филамент. Тест делается отдельной плоской моделью + ручным Z-offset на принтере во время печати. Методика — в [calibration/tests/first-layer/README.md](../calibration/tests/first-layer/), уточнение про меню Orca добавлено.

## План на ближайшую сессию

Перед стартом этапа 2 (cube → ortho → sorkin → threaded-fit) надо закрыть этап 1:

1. **Pre-flight.** Глянуть натяжение ремней, чистоту сопла, протереть стол (если есть IPA — IPA, если нет — насухо). Запустить Auto Leveling из меню.
2. **first-layer.** Скачать или сгенерировать в Orca плоскую модель `200×200×0.2 мм`, infill 100%, layer 0.2, perimeters 0. Печатать, в живую крутить Z-offset на экране принтера до момента «соседние линии сливаются без щелей и без размазывания». Записать значение, сохранить в профиль Orca, занести в `runs.md` теста.
3. **(Если IPA нет в момент сессии)** — first-layer можно сделать и так, но в шоппинг-листе IPA + безворсовые остаются как нужное на регулярной основе.

После этого штангенциркуль идёт в дело: cube + ortho в одном прогоне (один и тот же кубик), затем sorkin.
