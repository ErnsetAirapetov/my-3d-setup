# Шоппинг-лист

Что нужно докупить. Купленное → переносим в [inventory.md](inventory.md) (тот же коммит).

Категории совпадают с `inventory.md`. Внутри категории — пометка приоритета:

- **P1** — блокирует калибровку или ежедневную работу. Покупать в первую очередь.
- **P2** — нужно для нормального процесса (профилактика, частые задачи).
- **P3** — на будущее, для модов / редких случаев.

> Конкретные модели — это **рекомендации**, не догма. Подходящий аналог можно купить, заменить запись на купленный.

[inventory.md](inventory.md)) **уже закрыто** многое по категории «Обслуживание принтера» (мультитул Author, набор Mijia 24-в-1, набор торцевых 1/4", шестигранники), частично «Электроника» (вольтметр, паяльник, набор для пайки, индикатор 220 В). Список ниже — **остаток**.

## 1. Измерительные

- [ ] **P1 — Цифровой штангенциркуль 0.01 мм.** Без него калибровка после `first-layer` не работает (xyz-cube, ortho, sorkin, threaded-fit, flow-rate). Любой бюджетный нормальный (Shahe / Mitutoyo / no-name на ~1500–2500₽) подойдёт. Что важно: разрешение **0.01 мм** (не 0.05), губки внутренние и внешние, питание от батарейки CR2032.
- [ ] **P2 — Стальной угольник 90°** (100–150 мм). Для визуальной проверки ortho и для контроля при сборке модов.
- [ ] **P2 — Линейка стальная 200–300 мм.** Базовая мера для крупных деталей.
- [ ] **P3 — Фильмадиаметр-калибратор** (для замера диаметра филамента в нескольких точках катушки).

## 2. Снятие моделей и постобработка

- [ ] **P1 — Кусачки flush cutters (бокорезы для моделирования).** Подрезать filament на старте печати, отрезать брим, чистить нависы. Engineer NS-04 / Cresent / Knipex 78 — все рабочие. Главное: **flush** (срез вровень), не обычные «кусачки для гвоздей». Мультитул Author **не заменит** — там скорее открыватели/вилки, не flush-срез.
- [x] ~~**P1 — Пинцет средний.**~~ → **есть** (длинный изогнутый, см. inventory).
- [x] ~~**P1 — Шпатель / скребок металлический.**~~ → **есть** (3 лопатки в блистере подойдут).
- [ ] **P2 — Острый нож / скальпель** (X-Acto или сменные лезвия). Подрезать поддержки, чистить швы. Если в наборе для пайки уже есть нож-скальпель — можно вычеркнуть после уточнения.
- [ ] **P2 — Наждачка** разных гритов (200 / 400 / 800 / 1200) — постобработка поверхности.
- [ ] **P3 — Файлы / надфили** для тонкой подгонки отверстий и кромок.

## 3. Обслуживание принтера

- [ ] **P1 — Игла для прочистки сопла 0.4 мм** (acupuncture-style, со ручкой). На стоковом сопле 0.4 мм забивается рано или поздно. Часто продаётся набором 0.2/0.3/0.4/0.6/0.8.
- [x] ~~**P1 — Шестигранники / Allen keys.**~~ → **есть** в избытке (мультитул Author + длинные Г-образные + биты Mijia Hex + биты в наборе торцевых 1/4"). Размеры реальных шестигранников нужно замерить и записать в inventory.
- [ ] **P2 — Сменные сопла 0.4 мм** — 2–3 штуки про запас. Сопла дешёвые, забиваются. Для 5M Pro — high-flow сопла Flashforge (или совместимые).
- [ ] **P2 — Набор сопел разных диаметров:** 0.2 / 0.6 / 0.8 мм. Для тонкой детализации (0.2) и для быстрой/прочной печати (0.6, 0.8).
- [ ] **P3 — Запасной hotend assembly** (целиком) — на случай критического засора или ремонта. Заказывается у Flashforge.
- [ ] **P3 — Запасные термистор и нагреватель.**

## 4. Расходники

- [ ] **P1 — IPA (изопропиловый спирт) 99%, 250–500 мл.** Чистка стола перед каждой печатью / при потере адгезии.
- [ ] **P1 — Безворсовые салфетки** (микрофибра / медицинские) — наносить IPA на стол.
- [ ] **P2 — Клей-карандаш** (PVA, обычный школьный) или **3DLac** — для проблемной адгезии (PETG, ABS, мелкие детали).
- [ ] **P2 — Силикагель в гранулах** + **гермобоксы** для хранения филамента. PLA менее критичен, PETG/Nylon/PA-CF — критично.
- [ ] **P2 — Перчатки нитриловые** одноразовые (для работы со столом и расходниками).
- [ ] **P3 — Acetone** (ацетон) — только если будет ABS/ASA, для постобработки (vapor smoothing).

- [ ] **P3 — Кабель USB-C** для обновления прошивки / восстановления (когда дойдём до Forge-X / Klipper).

## 6. Безопасность

- [ ] **P2 — Термостойкие перчатки** (силиконовые / Kevlar) — для работы рядом с горячим соплом и столом.
- [ ] **P2 — Защитные очки** — на случай взлёта пружин / отлёта обрезков при флэш-кусанье.
- [ ] **P3 — Маска / респиратор** (FFP2 / N95) — обязательно при печати ABS / ASA / нейлона. PLA в нормальной комнате — без фанатизма.
- [ ] **P3 — Огнетушитель CO₂** в комнате с принтером (best practice).

## 7. Прочее

- [ ] **P2 — Кисть мягкая** для очистки стола и принтера от пыли (особенно вокруг направляющих).
- [ ] **P2 — Контейнеры для мелочи** (см. также [storage/](storage/) — там планируется напечатанная система).
- [ ] **P3 — UPS / стабилизатор** для принтера — особенно если в сети бывают скачки.
- [ ] **P3 — Стол / рабочая поверхность** под принтер: устойчивая, ровная, не вибрирующая.

## Реальный путь старта (минимум на P1 для калибровки) — после инвентаризации

| Что | Цель | Ориентир, ₽ |
| --- | --- | --- |
| Цифровой штангенциркуль 0.01 мм | без него калибровочные тесты не работают | 1500–2500 |
| Кусачки flush cutters | подрезка filament, брима, нитей | 800–2000 |
| Игла для прочистки сопла 0.4 мм (или набор) | расходник на сопло | 200–500 |
| IPA 99% 500 мл | чистка стола | 300 |
| Безворсовые салфетки (упаковка) | под IPA | 200 |

**Итого ориентировочно: ~3–5.5 тыс ₽** — и можно полноценно проходить калибровочные тесты этапа 2.
