# Шоппинг-лист

Что нужно докупить. Купленное → переносим в [inventory.md](inventory.md) (тот же коммит).

Категории совпадают с `inventory.md`. Внутри категории — пометка приоритета:

- **P1** — блокирует калибровку или ежедневную работу. Покупать в первую очередь.
- **P2** — нужно для нормального процесса (профилактика, частые задачи).
- **P3** — на будущее, для модов / редких случаев.

> Конкретные модели — это **рекомендации**, не догма. Подходящий аналог можно купить, заменить запись на купленный.

> Состояние на 2026-04-26: после первой инвентаризации (см. [inventory.md](inventory.md)) **уже закрыто** многое по категории «Обслуживание принтера» (мультитул Author, набор Mijia 24-в-1, набор торцевых 1/4", шестигранники), частично «Электроника» (вольтметр, паяльник, набор для пайки, индикатор 220 В). Список ниже — **остаток**.

## 1. Измерительные

- [ ] **P1 — Цифровой штангенциркуль 0.01 мм.** Без него калибровка после `first-layer` не работает (xyz-cube, ortho, sorkin, threaded-fit, flow-rate). Любой бюджетный нормальный (Shahe / Mitutoyo / no-name на ~1500–2500₽) подойдёт. Что важно: разрешение **0.01 мм** (не 0.05), губки внутренние и внешние, питание от батарейки CR2032.
- [ ] **P2 — Стальной угольник 90°** (100–150 мм). Для визуальной проверки ortho и для контроля при сборке модов.
- [x] ~~**P2 — Линейка стальная 200–300 мм.**~~ → **есть** (см. inventory).
- [ ] **P3 — Фильмадиаметр-калибратор** (для замера диаметра филамента в нескольких точках катушки).
- [ ] **P3 — Пузырьковый уровень малый** (~80–100 мм). Не для стола (auto-leveling справляется), а чтобы проверить, что сам принтер стоит ровно. Без фанатизма, на глаз тоже видно.

## 4. Расходники

- [ ] **P1 — IPA (изопропиловый спирт) 99%, 250–500 мл.** Чистка стола перед каждой печатью / при потере адгезии.
- [ ] **P1 — Безворсовые салфетки** (микрофибра / медицинские) — наносить IPA на стол.
- [x] ~~**P2 — Клей-карандаш.**~~ → **есть** из комплекта 5M Pro.
- [ ] **P2 — Силикагель в гранулах** + **гермобоксы** для хранения филамента. PLA менее критичен, PETG/Nylon/PA-CF — критично.
- [ ] **P2 — Перчатки нитриловые** одноразовые (для работы со столом и расходниками).
- [ ] **P3 — Acetone** (ацетон) — только если будет ABS/ASA, для постобработки (vapor smoothing).

## 6. Безопасность

- [ ] **P2 — Термостойкие перчатки** (силиконовые / Kevlar) — для работы рядом с горячим соплом и столом.
- [ ] **P2 — Защитные очки** — на случай взлёта пружин / отлёта обрезков при флэш-кусанье.
- [ ] **P3 — Маска / респиратор** (FFP2 / N95) — обязательно при печати ABS / ASA / нейлона. PLA в нормальной комнате — без фанатизма.
- [ ] **P3 — Огнетушитель CO₂** в комнате с принтером (best practice).

## 7. Прочее

- [ ] **P2 — Кисть мягкая** для очистки стола и принтера от пыли (особенно вокруг направляющих).
- [ ] **P2 — Контейнеры для мелочи** (см. также [storage/](storage/) — там планируется напечатанная система).
- [ ] **P3 — UPS / стабилизатор** для принтера — особенно если в сети бывают скачки.
- [ ] **P3 — Стол / рабочая поверхность** под принтер: устойчивая, ровная, не вибрирующая.

## Реальный путь старта (после полной инвентаризации)

После добавления стоковых позиций (flush cutters, игла, клей) **остался единственный блокер калибровки**:

| Что | Цель | Ориентир, ₽ |
| --- | --- | --- |
| Цифровой штангенциркуль 0.01 мм | блокер калибровочных тестов этапа 2 | 1500–2500 |
| IPA 99% 500 мл | чистка стола перед печатью | 300 |
| Безворсовые салфетки (упаковка) | под IPA | 200 |

**Итого: ~2–3 тыс ₽** на минимум для старта.
