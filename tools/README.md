# tools/ — физические инструменты, расходники и хранение

Учёт инструментов и расходников, нужных для нормальной работы с принтером, плюс планирование системы хранения.

## Что внутри

- [inventory.md](inventory.md) — что **уже есть в наличии**, по категориям. Заполняем по мере того как приходит/находится.
- [shopping-list.md](shopping-list.md) — что **нужно докупить**, по категориям и приоритетам. Купленное переезжает в `inventory.md`.
- [storage/](storage/) — система хранения: концепция, выбранный подход, печатные модули.
- [photos/](photos/) — фото инвентаря (соглашение об именовании внутри).

## Принципы

- **Категории те же** в `inventory.md`, `shopping-list.md` и `storage/` — чтобы навигация была сквозной.
- **Купил → перенёс из shopping-list.md в inventory.md** в одном коммите.
- **Сначала инвентаризация, потом покупки.** Чтобы не дублировать имеющееся.
- **Сначала инвентаризация, потом дизайн хранения.** Без понимания, что и сколько хранить, любой план хранения будет вилами по воде.
