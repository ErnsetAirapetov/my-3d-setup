# tools/photos/ — фото инвентаря

Сюда складываются фото инструментов и расходников из [../inventory.md](../inventory.md).

## Соглашение об именовании

Формат: `<номер-категории>-<краткое-имя>.jpg`

Категории те же, что в `inventory.md`:

| # | Категория |
| --- | --- |
| 1 | Измерительные |
| 2 | Снятие моделей и постобработка |
| 3 | Обслуживание принтера |
| 4 | Расходники |
| 5 | Электроника и диагностика |
| 6 | Безопасность |
| 7 | Прочее |

Примеры:

- `1-caliper-shahe.jpg`
- `2-flush-cutters-engineer.jpg`
- `3-allen-keys-set.jpg`
- `4-ipa-500ml.jpg`

Если **одно фото на несколько предметов** (общий план категории) — `1-overview.jpg`, `2-overview.jpg` и т.п.

## Что коммитим, что нет

- ✅ Обычные `.jpg` / `.png` — коммитим. Они нужны как часть инвентаря.
- ❌ Тяжёлые исходники с телефона (5–10 МБ) — пережать перед коммитом до **~500 КБ–1 МБ** (1600 px по длинной стороне обычно достаточно).
- ❌ Видео — не сюда (см. `.gitignore`, видео исключены).

## Ссылки в `inventory.md`

В колонке `Фото` использовать markdown-ссылку на относительный путь:

```markdown
| Штангенциркуль Shahe 0.01 | 1 | ящик 1 | новый | [📷](photos/1-caliper-shahe.jpg) | питание CR2032 |
```

Это сделает ссылку кликабельной прямо из таблицы.
