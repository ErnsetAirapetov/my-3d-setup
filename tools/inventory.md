# Инвентарь инструментов и расходников

Всё, что **уже есть** в наличии, разбито по категориям. Купленное из [shopping-list.md](shopping-list.md) переезжает сюда.

## Шаблон записи

| Поле | Пояснение |
| --- | --- |
| `Что` | название (модель если важно) |
| `Кол-во` | штук / мл / гр |
| `Где лежит` | конкретное место (или ссылка на модуль в [storage/](storage/)) |
| `Состояние` | новое / б/у / надо заменить |
| `Фото` | ссылка на файл в [photos/](photos/) — имя `<категория>-<что>.jpg` |
| `Заметки` | особенности, что не так с конкретным экземпляром |

> Если фото нет — поставь прочерк `—`. Лучше пустое поле, чем выдуманная ссылка.
