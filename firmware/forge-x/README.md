# firmware/forge-x/

Заметки, бэкапы и конфиги для **Forge-X mod** — модификации стоковой прошивки Flashforge, открывающей рут-доступ. Промежуточный шаг между stock и Klipper.

## Что хранить

- Версия мода и дата установки.
- Источник (официальный репозиторий / форк), ссылки.
- Пошаговая процедура установки, как её прошёл сам.
- Заметки о том, что изменилось после установки.
- Конфиги, если меняли что-то на уровне ОС/сервисов.
