# firmware/klipper/

Всё по Klipper: конфиги, макросы, заметки по установке.

## Что внутри

- [configs/](configs/) — `printer.cfg`, конфиги Moonraker / Mainsail / Fluidd, оверлеи под конкретные апгрейды.
- [macros/](macros/) — пользовательские макросы (`START_PRINT`, `END_PRINT`, `PAUSE`, `LOAD_FILAMENT`, `RUNOUT` и т.д.).

## Принципы

- **Один источник правды.** Реальный `printer.cfg` на принтере должен совпадать с тем, что лежит здесь. Любая правка — сначала сюда (или в репу), потом на принтер.
- **Версионирование макросов.** Макросы выносим в отдельные файлы и подключаем `[include]`, чтобы можно было диффать.
- **Бэкап перед каждой существенной правкой.** Особенно перед сменой драйверов, добавлением сенсоров или новых модулей.
