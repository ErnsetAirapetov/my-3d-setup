# firmware/klipper/macros/

Пользовательские макросы Klipper. Один макрос (или связка) — один файл, подключаемый через `[include]` в `printer.cfg`.

Типичный набор: `START_PRINT`, `END_PRINT`, `PAUSE`, `RESUME`, `CANCEL_PRINT`, `LOAD_FILAMENT`, `UNLOAD_FILAMENT`, `RUNOUT`, `BED_MESH_CALIBRATE_FAST`.
