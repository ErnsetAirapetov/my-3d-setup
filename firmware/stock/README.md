# firmware/stock/

Бэкапы и снимки заводской прошивки. Сюда складываем всё, что нужно, чтобы при необходимости откатиться к стоку.

## Что хранить

- Версии прошивки (числа, даты).
- Файлы прошивки, если их можно скачать с официального сайта (или ссылки).
- Скриншоты заводских настроек принтера (меню, сетевые параметры).
- Экспорт настроек из приложения Flashforge, если такое есть.
