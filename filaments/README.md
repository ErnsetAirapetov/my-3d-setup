# filaments/ — учёт филаментов

Учёт катушек филамента и накопленные знания по разным типам/брендам.

## Что внутри

- [inventory.md](inventory.md) — таблица катушек: что в наличии, остатки, даты.
- [notes/](notes/) — заметки по типам/брендам: рабочие температуры, особенности, что хорошо печатается, что нет.

## Связь со слайсером

Откалиброванные настройки филамента лежат как профили в [../slicer/filament/](../slicer/filament/). Здесь — человекочитаемые заметки и инвентарь, не конфиги.
