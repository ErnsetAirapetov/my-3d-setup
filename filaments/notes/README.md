# filaments/notes/

Заметки по типам филаментов, не привязанные к конкретной катушке. Один тип — один файл: `pla.md`, `petg.md`, `abs.md`, `tpu.md`, `pa-cf.md` и т.д.

В файл по типу складываем общие наблюдения: рабочие диапазоны температур, требования к сушке, склонность к стрингам/варпингу, какие сопла нужны (особенно для абразивных), какие профили в слайсере хорошо себя показали.

Заметки **по конкретным катушкам** идут в колонке «Заметки» в [../inventory.md](../inventory.md).
